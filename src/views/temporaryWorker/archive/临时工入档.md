# 临时工入档（archive）

劳动派遣人员的入档管理页面：将访客中心中**已通过审批的劳动派遣登记记录**批量录入为临时工档案，并按工种名额分配部门/岗位。

- 页面组件名：`TemporaryWorkerArchive`
- 创建日期：2026-09-29
- 原型文件：[临时工入档.html](../临时工入档.html)
- 接入文档：[modules/临时工入档-前端接入.md](./modules/临时工入档-前端接入.md)

## 目录结构

```text
archive/

├── README.md                      # 本文档

    └── 临时工入档-前端接入.md      # 后端接口接入说明（接口字段、口径、异常文案）
```

## 页面功能

1. **顶部统计卡片**：劳动派遣总数 / 未入档 / 已入档，数据来自状态统计接口。
2. **筛选区**：
   - 访客姓名（`xm`，模糊查询）、接待人（`jdr`，模糊查询）
   - 派遣公司（`pqgs`，字典 `hrm_fkzx_sq_pqgs`，`j-dict-select-tag`）
   - 预计来访时间区间（`yjlfsj_begin` / `yjlfsj_end`，`j-date`）
3. **状态 Tab**：未入档 / 已入档胶囊切换；仅【未入档】记录可勾选，已入档记录勾选框置灰。
4. **表格**：展示劳动派遣记录（序号、状态、姓名、联系方式、身份证、来访类型、派遣公司、预计来访时间、接待人等），操作列提供「详情」。
5. **批量操作**：
   - **添加进入临时工**：勾选未入档记录后打开 `AddWorkerModal`，按工种批量录入。
   - **删除**：勾选后经 `DeleteModal` 二次确认，调用批量删除接口。
6. **详情**：复用访客中心的 [EmployeeVisitorDetail.vue](../../visitor/modules/EmployeeVisitorDetail.vue)，以 `detailType=temp` 打开。

## 业务流程

```text
劳动派遣登记审批通过（访客中心）
        │
        ▼
  本页列表（lflx=4 劳动派遣, zt=1 已通过）
        │  勾选未入档记录
        ▼
  AddWorkerModal
   ├─ 打开时调 listWorkTypes 获取工种与剩余名额
   ├─ 选择工种 → 按 deptList 渲染逐人分配预览（默认 deptList[0]，可手动改选）
   ├─ 名额动态提示：名额充足 / 恰好占满 / 超出名额（超出者暂不分配岗位）
   └─ 确认提交 addByLdpq（ldpqIds 按勾选顺序，assignList 逐人指定部门）
        │
        ▼
  成功 → 清空勾选、刷新列表与统计，记录进入「已入档」Tab
```

> 剩余名额为实时数据，前端校验仅作交互提示，最终以后端提交结果为准；`success=false` 时弹窗保持打开，展示后端 message 便于修改重提。

## 组件说明

### index.vue

基于 `JeecgListMixin`，但设置 `disableMixinCreated: true` 禁用混入自动加载，由 `created` 主动调用 `loadData(1)` 与 `loadStatCounts()`。

主要方法：

| 方法 | 说明 |
|---|---|
| `loadData(arg)` | 覆盖 mixin：查询列表，姓名/接待人按 JEECG `*xxx*` 规则拼模糊条件；`arg === 1` 回到第一页 |
| `loadStatCounts()` | 调 `/commonTj/ztTjInfo/getTjListByCodes`（编码 `lsgrd`），按 `is_lsgda` 汇总未入档/已入档数量 |
| `changeTab(key)` | 切换 Tab，写入 `queryParam.isLsgda`（`'0'` 未入档 / `'1'` 已入档）并重新加载 |
| `searchReset()` | 覆盖 mixin：重置为完整的 `queryParam` 字段结构并回到未入档 Tab |
| `handleAdd()` | 校验已勾选后打开 `AddWorkerModal`，传入 `selectionRows` |
| `handleAddWorkerOk()` | 录入成功回调：清空勾选、刷新列表与统计 |
| `handleDelete()` / `confirmDelete()` | 打开删除确认弹窗 / 调批量删除接口后刷新 |
| `handleDetail(record)` | 打开访客详情弹窗：`show(record, '劳动派遣详情', false, 'temp')` |
| `isArchived(record)` | `isLsgda === '1'`（兼容数字 `1`）即已入档 |

固定查询参数（`queryParam`）：

| 参数 | 值 | 含义 |
|---|---|---|
| `lflx` | `'4'` | 来访类型：劳动派遣 |
| `zt` | `'1'` | 审批状态：已通过 |
| `isLsgda` | `'0'` / `'1'` | 入档状态，随 Tab 切换 |
| `column` / `order` | `createTime` / `desc` | 默认按创建时间倒序 |

### AddWorkerModal.vue

通过 `ref` 调用 `show(records)` 打开；`records` 为勾选的接口原始记录（需含 `id`、`xm`）。

- 打开时调 `GET /lsggl/tempWorkerApply/listWorkTypes`（免登录）加载工种下拉，选项文案用接口的 `label`（如 `包装工（剩余 3 人）`）。
- `assignments` 计算属性：手动改选（`deptOverrides`）优先，其余按 `deptList` 顺序填入有名额的部门；名额耗尽的行 `dept` 为 `null`，展示「超出需求名额，暂不分配岗位」。
- `alert` 计算属性：按剩余名额与勾选人数生成三种提示（常规 / 恰好占满 / 超出名额）。
- 提交 `POST /lsggl/tempWorkerArchive/addByLdpq`：`ldpqIds` 为勾选顺序的 id 列表，`assignList` 逐人传 `{ ldpqId, itemId }`，不分配者 `itemId` 传 `''` 走后端自动匹配。
- 事件：成功关闭并 `@emit('ok')`，父组件据此刷新。

### DeleteModal.vue

| 类型 | 名称 | 说明 |
|---|---|---|
| props | `visible` | 显示状态，支持 `.sync` |
| props | `count` | 待删除记录条数，用于文案 |
| events | `ok` | 点击「确定删除」，删除逻辑由父组件执行 |

## 接口清单

| 接口 | 方法 | 说明 |
|---|---|---|
| `/fkzx/hrmFkzxSq/list` | GET | 劳动派遣登记列表（已通过），分页查询 |
| `/fkzx/hrmFkzxSq/deleteBatch` | DELETE | 批量删除劳动派遣记录，参数 `ids`（逗号拼接） |
| `/commonTj/ztTjInfo/getTjListByCodes` | POST | 状态统计，请求体 `{ lsgrd: {} }` |
| `/lsggl/tempWorkerApply/listWorkTypes` | GET | 工种/名额分组查询（免登录） |
| `/lsggl/tempWorkerArchive/addByLdpq` | POST | 录入临时工档案并逐人分配部门（需登录） |

> 后端 context-path 为 `/qr-hrm`；完整字段、响应示例与异常口径见 [modules/临时工入档-前端接入.md](./modules/临时工入档-前端接入.md)。

## 依赖与样式

- 混入：[JeecgListMixin](../../../mixins/JeecgListMixin.js)（`selectedRowKeys`、`selectionRows`、`onSelectChange`、`ipagination` 等）
- API：`getAction` / `postAction` / `deleteAction`（`@/api/manage`）
- 组件：`JDate`（`@/components/jeecg/JDate`）、`j-dict-select-tag`（全局）、访客详情 `EmployeeVisitorDetail`
- 样式：引入 [temporary-worker-theme.less](../temporary-worker-theme.less)（定义 `@v-border`、`@v-shadow-card`、`@v-gradient-blue`、`@v-foreground` 等 Less 变量）；弹窗渐变头部、统计卡片等局部样式在各组件 `scoped` 中定义。
- 页面采用整页滚动（根容器 `overflow-y: auto`，表格内部滚动置为 `visible`）。
