## 模块概述

临时工面试模块用于对**劳动派遣来访人员**进行面试结果管理。数据来源于访客中心申请（`hrm_fkzx_sq`）中「来访类型 = 劳动派遣」且审批已通过的记录，支持批量登记面试结果（未面试 / 已通过 / 不通过）。

### 核心功能

- **统计概览**：劳动派遣总数、未面试、已通过、不通过四张统计卡片
- **条件筛选**：访客姓名、接待人、派遣公司、预计来访时间范围
- **状态切换**：未面试 / 已通过 / 不通过胶囊 Tab 快速切换
- **批量登记**：勾选多条记录后一次性登记面试结果
- **详情查看**：复用访客中心详情弹窗查看原始登记信息
- **联动入档**：面试结果为「已通过」的数据将自动进入临时工入档环节

### 技术栈

- Vue 2.6 Options API + ant-design-vue 1.7
- `JeecgListMixin` 列表混入
- Less + 模块主题文件 `temporary-worker-theme.less`
- JEECG `getAction` / `postAction` 请求封装

## 功能说明

### 1. 列表查询

- 固定查询条件：`lflx=4`（劳动派遣）、`zt=1`（审批已通过）
- 默认按创建时间（`createTime`）倒序排列
- 访客姓名、接待人按 JEECG 通配规则做模糊查询，提交时自动包装为 `*关键词*`
- 通过 `disableMixinCreated: true` 关闭混入的自动加载，由页面 `created` 主动调用 `loadData(1)`

### 2. 状态 Tab

| key | 状态 | 数量字段 |
|-----|------|----------|
| `0` | 未面试 | `counts.none` |
| `1` | 已通过 | `counts.pass` |
| `2` | 不通过 | `counts.fail` |

切换 Tab 时更新 `queryParam.mszt` 并回到第一页重新加载。

### 3. 批量面试登记

1. 勾选表格记录后点击「面试」按钮（未勾选时 `$message.warning` 提示）
2. 打开 `InterviewModal`，以 chips 形式展示已勾选人员姓名
3. 选择「已通过」或「不通过」后提交
4. 登记成功后清空勾选，并刷新列表与顶部统计

### 4. 查看详情

调用 `this.$refs.detailModal.show(record, '劳动派遣详情', false, 'temp')`，复用访客中心的 `EmployeeVisitorDetail` 组件，`detailType=temp` 表示劳动派遣详情场景。

## API 接口

### 1. 劳动派遣记录列表

```http
GET /fkzx/hrmFkzxSq/list
```

查询参数为 `queryParam` 各字段 + `pageNo`、`pageSize`，返回 JEECG 分页结构 `result.records` / `result.total`。

### 2. 顶部状态统计

```http
POST /commonTj/ztTjInfo/getTjListByCodes
```

请求体：

```json
{ "hrm_fkzx_sq": {} }
```

从返回的 `result.hrm_fkzx_sq.mszt_tj` 中按 `mszt` 文案（已通过 / 不通过 / 其余视为未面试）汇总数量，总数 `all = none + pass + fail`。

### 3. 批量更新面试状态

```http
GET /fkzx/hrmFkzxSq/updateMszt
```

| 参数 | 说明 |
|------|------|
| `ids` | 记录 ID，英文逗号拼接 |
| `mszt` | 目标面试状态：`1`-已通过，`2`-不通过 |

成功后由弹窗 `$emit('ok')` 通知主页面刷新。

## 组件说明

### `TemporaryWorkerInterview`（`index.vue`）

主页面，混入 `JeecgListMixin`。

**核心方法**：

| 方法 | 说明 |
|------|------|
| `loadData(arg)` | 加载列表，`arg === 1` 时回到第一页；处理姓名/接待人模糊包装 |
| `loadStatCounts()` | 加载顶部统计数量 |
| `changeTab(key)` | 切换面试状态 Tab |
| `searchReset()` | 重置筛选（覆盖混入方法，保留完整 `queryParam` 字段结构） |
| `handleInterview()` | 校验勾选并打开面试登记弹窗 |
| `handleInterviewOk()` | 登记成功回调：清空勾选、刷新列表与统计 |
| `handleDetail(record)` | 打开访客详情弹窗（`detailType=temp`） |
| `interviewStatusText/Class(value)` | 面试状态文案与样式映射 |
| `isArchived(record)` | 判断记录是否已入档 |

### `InterviewModal`（`modules/InterviewModal.vue`）

面试结果登记弹窗。

**对外方法 / 事件**：

- `show(records)`：传入勾选记录数组（需含 `id`、`xm`），打开弹窗并重置选择
- `@ok`：登记成功后触发

**内部逻辑**：

- `result`：本次面试结果，`'1'`-已通过 / `'2'`-不通过
- `alreadyPassCount` / `alreadyFailCount`：勾选中已有面试结果的条数，大于 0 时展示黄色「覆盖登记」提醒
- 内置二级报错弹窗（红色头部）：预留给「已入档不可修改」等拦截场景，对应校验逻辑当前在 `handleOk` 中以注释保留

## 业务流转

```
访客中心登记（来访类型=劳动派遣）
        │ 审批通过（zt=1）
        ▼
   临时工面试（本模块）
        │
        ├── 已通过（mszt=1）──► 自动进入临时工入档（archive / file）
        ├── 不通过（mszt=2）
        └── 未面试（mszt=0，默认状态）
```

> 已支持对「已通过 / 不通过」的记录重新登记，操作时弹窗会给出覆盖提醒。

## 相关约定

- 样式：`<style lang="less" scoped>`，通过 `@import '../temporary-worker-theme.less';` 引入主题变量（如 `@v-border`、`@v-shadow-card`、`@v-gradient-blue`）
- 滚动：页面根容器采用 flex 纵向布局并由整页 `overflow-y: auto` 滚动，表格区域 `.v-content` / `.v-scroll-area` 取消内部滚动限制
- 请求统一使用 `@/api/manage` 的 `getAction` / `postAction`，成功判断 `res.success`，失败用 `$message` 提示
- 字典：派遣公司使用 `j-dict-select-tag` 配合字典编码 `hrm_fkzx_sq_pqgs`
