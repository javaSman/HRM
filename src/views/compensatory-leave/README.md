# 补休管理模块

> 补休申请与记录管理

## 概述

补休管理模块用于处理员工的补休申请，与加班时长关联。

## 子模块

| 目录 | 功能 |
|------|------|
| `compensatory-leave-management/` | 补休管理 |

## 核心功能

- 补休申请
- 补休余额查询
- 补休记录管理
- 加班转补休

## 补休规则

- 加班 1 小时可转换补休时长
- 补休有效期限制
- 补休审批流程
