# 销假申请模块

## 模块说明

销假申请（提前结束请假回到岗位）的申请与审批模块，基于 JeecgBoot 前端框架开发，布局、样式与加班（ot）、请假（leave）、外出（fieldWork）等考勤申请模块保持统一。

- 申请端：员工选择销假类型 → 选择请假单 → 填写实际到岗时间（日期 + 打卡时段）→ 提交审批。
- 审批端：当前节点审批人审批通过 / 退回，支持撤回、修改重申、抄送我的、字段配置、导出等。
- 一个列表组件通过 `boxState` 参数同时支撑「申请页」和「审批页」两种视角。

## 页面模式（boxState）

[index.vue](index.vue) 通过 prop `boxState` 区分视角，[approval.vue](approval.vue) 仅做薄包装：

```vue
<!-- 申请页 -->
<Index :boxState="0" />
<!-- 审批页（approval.vue 的全部实现） -->
<Index :boxState="1" />
```

| 模式 | Tab（value = spStatus） | 数据来源 |
| --- | --- | --- |
| 申请页 boxState=0 | 审批中(1) / 已通过(2) / 已退回(4) / 已撤回(3) | `list` 接口 |
| 审批页 boxState=1 | 待审批(1) / 已审批(2+4) / 抄送我的(99) | `list` 接口；抄送 Tab 走 `queryCsrList` |

- Tab 标题后的数量徽标由 `getSpStatusCount` 接口返回，「已审批」数量为 **已通过(2) + 已退回(4)** 之和（见 `getCount`）。
- 审批页「已审批」Tab 使用 Jeecg 高级查询（`superQueryMatchType='or'`，字段 `spStatus` int，eq 2 / eq 4）。
- 「抄送我的」`spStatus=99` 仅为前端 Tab 标识，不下发后端；查询时删除该参数并改传当前登录人工号 `csrNo`。
- 各 Tab 数量随 `dataSource` 变化自动刷新（`watch dataSource → getCount`）。

## 状态定义

| 字段 | 值 | 含义 | 标签颜色 |
| --- | --- | --- | --- |
| `spStatus` | 1 | 审批中 | 橙 `#fa8c16` |
| `spStatus` | 2 | 已通过 | 绿 `#55c42a` |
| `spStatus` | 3 | 已撤回 | 蓝 `#0082fc` |
| `spStatus` | 4 | 已退回 | 红 `#f5222d` |
| `spFlow` | - | 当前审批节点名称（如部门经理、HR） | - |
| `brSpStatus` | 1 | 后端返回的「当前节点可审批」标识，列表审批按钮需同时满足此标识 | - |

状态流转：

```
新增提交 ──► 审批中(1) ──通过──► 已通过(2)
                │  └──退回──► 已退回(4) ──修改重申(resubmit)──► 审批中(1)
                └──撤回(updateWithdraw)──► 已撤回(3)
已退回(4) / 已撤回(3) 可由申请人本人删除
```

## 列表操作列规则

| Tab | 可见操作 | 权限条件 |
| --- | --- | --- |
| 申请页·审批中 | 撤回、详情 | 撤回仅申请人本人（`isApplyOwner`，行 `no` = 当前登录工号） |
| 申请页·已通过 | 详情 | 所有人 |
| 申请页·已退回 | 修改重申、删除、详情 | 修改 / 删除仅申请人本人 |
| 申请页·已撤回 | 删除、详情 | 删除仅申请人本人 |
| 审批页·待审批 | 审批、详情 | 审批需 `isCurrentApprover(record) && record.brSpStatus == 1` |
| 审批页·已审批 / 抄送我的 | 详情 | 所有人 |

`isCurrentApprover` 判断逻辑：取行数据 `customProcessSqdSpjdList` 中 `nodeName == spFlow`（当前节点）的**最后一条**记录（同节点多次驳回会有多条），其中 `sprId` / `sprName` 可能是逗号分隔多人，依次按 **用户 ID → 工号（抄送节点 sprId 存工号）→ 姓名** 匹配当前登录用户。

## 搜索与表格

- 搜索条件：公司（`/org/hrmOrg/loadTreeRoot?pid=0`）、所属部门（公司下级树，级联可选任意层级，末级 id 入参 `dept`）、工号、姓名、销假类型（字典 `xj_type`）。
- 「审批中 / 待审批」Tab 额外显示「当前节点（spFlow）」「审批人」列，其他 Tab 隐藏审批人列。
- 时长列 `actualHours` 拼接单位字段 `actualHoursDw`（天 / 小时）展示。
- 「字段配置」按钮使用公共组件 `ColumnConfigSidebar` + `columnConfigMixin`，列配置编码 `columnCode = 'LeaveResumptionApply'`。
- 支持导出（`exportXls`，导出名「销假申请表」）、行选择与批量删除（`deleteBatch`）。

## 弹窗模式（LeaveResumptionModal）

统一使用 `j-modal`（宽 1100px，`wrapClassName="attendance-rule-modal"`），由 `title` 驱动模式：

| title | 表单 | 底部按钮 |
| --- | --- | --- |
| 新增销假 | 可编辑 | 取消 / 提交申请 |
| 修改重申 | 可编辑，右栏顶部先展示**上一轮审批时间轴**（含退回原因） | 取消 / 修改并提交 |
| 审批 | 只读，右栏为审批意见输入（选填） | 取消 / 审批不通过 / 审批通过 |
| 详情 | 只读，右栏为完整审批流程时间轴 | 关闭 |

审批口径参考外出申请（ServiceLeaveModal）：审批意见均**选填**，点击后二次确认再请求；请求体为
`{ spStatus, sprId: 当前登录人id, id, spOpinion }`。

## 表单与业务校验（LeaveResumptionApplyForm）

左右两栏：左侧申请信息，右侧动态审批流程（新增）或审批时间轴（详情/重申）或审批意见（审批）。

### 表单字段

| 字段 | 控件 | 必填 | 说明 |
| --- | --- | --- | --- |
| 公司 / 所属部门 / 工号 / 姓名 | 禁用输入框 | - | 自动取本地缓存 `perInfo`，回显取 `*_dictText` |
| 申请时间 `createTime` | 禁用输入框 | - | 仅详情、审批展示，取后端创建时间 |
| `xjType` 销假类型 | 下拉（字典 `xj_type`） | 是 | 字典 **value 即类型文本**（如「年假」），与请假申请口径一致；切换后清空已选请假单并重新拉取列表 |
| `hrXjsqId` 假期列表 | 下拉 | 是 | 调 `queryCanCancelLeaveList`，按当前工号 + 销假类型查询可销假请假单，选项格式 `开始 ~ 结束（时长）` |
| `actualEndTime` 到岗时间 | 日期（j-date）+ 到岗时段下拉 | 是 | 日期 `YYYY-MM-DD`；时段取打卡规则中的打卡时刻 `HH:mm`，提交时拼成 `YYYY-MM-DD HH:mm:ss` |
| `xjyy` 销假原因 | 文本域 | 是 | - |
| `attachmentUrls` 附件 | JUploadList | 否 | - |
| 原请假时长 / 原请假结束时间 / 实际请假时长 / 额度调整 | 只读 | - | 仅详情、审批展示；原请假时长取后端快照 `originalHours`（年假拼天、其他假拼小时），`actualHours`/`edtz` 拼 `actualHoursDw` 单位；`originalEndTime` 为销假前快照 |

- 时长口径：销假类型为「年假」时按天（`applyDays`），其他类型按小时（`applyHours`），与请假列表一致。
- 到岗时段来源：`/hrm/hrKqRule/getHrKqRuleGddatedkByNo`（按工号取固定打卡时段，收集各时段上班 `sbdaate` / 下班 `xbdate` 去重排序）；当员工打卡规则时段不完整时，按规则说明 `ruleSm` 从系统变量 `/variableRescord/sysVariableRecord/getInfo/hr_kq_rule` 兜底匹配。
- 详情 / 审批回显：可销假列表不含已销假 / 审批中的请假单，因此假期下拉直接用列表行嵌套的 `hrXjsq` 原请假单构造（`applyLeaveOrderFromHrXjsq`），时段下拉用 `actualEndTime` 拆出的时分构造单选项，不调接口。

### 提交前校验（submitForm）

1. 表单必填校验（销假类型、请假单、到岗日期、销假原因）。
2. 到岗时段必选（合并在到岗时间表单项内，手动校验）。
3. 销假时效：当前时间必须**早于请假结束时间**，否则提示「当前时间已超过请假结束时间，不能进行销假！」。
4. 到岗范围：日期 + 时段拼成的完整时刻必须在请假开始 ~ 结束时间范围内。
5. 审批节点校验：`ApprovalProcess.validate()`，需自选审批人 / 抄送人的节点不能为空。

### 提交处理

- 新增 → `POST .../add`；修改重申 → `POST .../resubmit`。
- 组装 `customProcessConfigurationDTOList = $refs.approvalProcess.getCustomProcessList()` 一并提交。
- `actualEndTime` 拼接为 `YYYY-MM-DD HH:mm:ss`；前端辅助字段 `arrivalPart`、嵌套对象 `hrXjsq` 提交前剔除（不入库）。

## 审批流程组件（ApprovalProcess）

本模块 `modules/ApprovalProcess.vue` 为公共动态节点组件，销假申请与外出申请（`serviceLeaveApply/modules/ServiceLeaveApplyForm.vue`）共同引用。

- Props：`sqmkCode`（销假传「销假申请」）、`dept`、`no`、`disabled`。
- 节点接口：`GET /process/customProcessConfiguration/getLcjdList`，按 `px` 排序；部门变化时自动重新加载。
- 节点能力：
  - `nodeProperties`：1=审批节点，2=抄送节点；
  - `approvalRule`：1=会签（橙标签），2=或签（红标签）；
  - `isselfSelect=1` 或 `sprScope=4`：可通过 `j-select-employee` / `j-select-approver` 自选人员，标签可删除；
  - 空级审批（直属主管 / 经理 / 总监，按 `kjSprType` 识别）：走「自选审批人」；
  - `users === null` 且有 `chooseObjectsName`：直接展示后端解析的人员文案。
- 对外暴露：`loadProcessNodes()`、`reset()`、`validate()`、`getCustomProcessList()`（把所选人员写回节点外层 `chooseObjects` / `chooseObjectsName`，逗号分隔）。

## 撤回弹窗（LeaveResumptionRevokeModal）

- 仅审批中（spStatus=1）且申请人本人可撤回，撤回后 spStatus=3。
- 撤回原因 `spOpinion` 选填（最多 500 字），弹窗不可点遮罩 / 右上角关闭，防误操作。
- 请求：`POST /hr_kq_xjgl/hrKqXjgl/updateWithdraw`，body 为 `{ ...record, spStatus: 3, spOpinion }`。

## 审批日志抽屉（LeaveResumptionApplyLog）

- 接口 `GET /hr_kq_xjgl/hrKqXjgl/getFlowList?id=`，时间轴展示节点、审批人、时间、意见，支持 done / active / rejected / returned / cancel 五种节点配色。
- 列表操作列中的「日志」入口当前在 [index.vue](index.vue) 模板中以注释屏蔽，需要时恢复「日志」两行注释即可；弹窗内的历史记录展示统一使用请假模块的 `ApprovalTimeline`。

## 字典与主要字段

- 字典编码：`xj_type`（销假类型，value 为类型文本）。
- 后端表：`hr_kq_xjgl`（实体 HrKqXjgl）。

| 字段 | 含义 |
| --- | --- |
| `companyId` / `dept` / `no` / `name` / `employeeId` / `positionName` | 公司、部门、工号、姓名、员工ID、岗位 |
| `xjType` | 销假类型（字典 xj_type 文本值） |
| `hrXjsqId` | 原请假单 ID |
| `hrXjsq` | 列表行嵌套的原请假单对象（仅前端回显用，不入库） |
| `actualEndTime` | 实际到岗时刻 `YYYY-MM-DD HH:mm:ss` |
| `createTime` | 申请时间（后端创建时间，仅详情/审批展示） |
| `actualHours` / `actualHoursDw` | 实际请假时长 / 单位（天、小时），后端按到岗时间计算 |
| `originalHours` | 原请假时长（销假前快照，后端返回；年假单位天、其他假单位小时） |
| `originalEndTime` | 原请假结束时间（销假前快照 `YYYY-MM-DD HH:mm:ss`，后端返回） |
| `edtz` | 额度调整（单位同 actualHoursDw，后端返回） |
| `xjyy` | 销假原因 |
| `attachmentUrls` | 附件 |
| `spStatus` / `spFlow` / `sprName` / `spOpinion` | 审批状态 / 当前节点 / 审批人 / 审批（撤回）意见 |
| `brSpStatus` | 当前节点是否可审批（1=可审批） |
| `customProcessSqdSpjdList` | 当前轮次审批节点记录（含 nodeName、sprId、sprName） |
| `customProcessConfigurationDTOList` | 提交时携带的审批节点配置 |
