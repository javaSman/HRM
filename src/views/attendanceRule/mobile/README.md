# 移动打卡模块

## 模块概述

本模块用于管理员工移动打卡申请和打卡记录查询，支持员工通过移动端申请打卡，审批人进行审批，以及打卡记录的查询和统计。

## 文件结构

```
mobile/
├── HrMobileApplyList.vue      # 移动打卡申请列表
├── HrPunchRecordList.vue      # 移动打卡记录列表
├── modules/
│   ├── HrMobileApplyModal.vue    # 移动打卡申请弹窗
│   └── HrPunchRecordModal.vue    # 移动打卡记录弹窗

```

## 核心功能

### 1. 移动打卡申请管理 (HrMobileApplyList.vue)

#### 双模式切换
模块支持两种角色模式：
- **申请人端**：员工提交和管理自己的移动打卡申请
- **审批人端**：审批人员审核和处理移动打卡申请

#### 主要功能
- **申请列表**：查看移动打卡申请记录
- **新增申请**：提交新的移动打卡申请
- **审批处理**：审批人审核申请（同意/拒绝）
- **状态筛选**：按申请状态筛选（待审批、已同意、已拒绝）
- **数据导出**：导出申请记录为 Excel

#### 申请字段

| 字段名 | 说明 | 备注 |
|--------|------|------|
| 申请人 | 提交申请的员工 | 自动获取当前用户 |
| 申请时间 | 提交申请的时间 | 系统自动记录 |
| 打卡日期 | 申请打卡的日期 | 用户选择 |
| 打卡时间 | 申请打卡的具体时间 | 用户填写 |
| 打卡类型 | 上班打卡/下班打卡 | 用户选择 |
| 打卡地点 | 打卡位置信息 | 移动端获取 |
| 申请理由 | 申请移动打卡的原因 | 用户填写 |
| 审批状态 | 待审批/已同意/已拒绝 | 系统状态 |
| 审批人 | 审批该申请的人员 | 系统记录 |
| 审批意见 | 审批人的审批意见 | 审批人填写 |

### 2. 移动打卡记录查询 (HrPunchRecordList.vue)

#### 主要功能
- **记录列表**：查看所有移动打卡记录
- **照片预览**：查看打卡时拍摄的照片
- **条件筛选**：按员工、日期、部门等条件筛选
- **数据导出**：导出打卡记录为 Excel

#### 记录字段

| 字段名 | 说明 | 备注 |
|--------|------|------|
| 员工姓名 | 打卡员工姓名 | - |
| 工号 | 员工工号 | - |
| 部门 | 员工所属部门 | - |
| 打卡日期 | 打卡的日期 | - |
| 打卡时间 | 具体打卡时间 | - |
| 打卡类型 | 上班/下班 | - |
| 打卡地点 | 打卡时的位置 | GPS定位 |
| 打卡照片 | 打卡时拍摄的照片 | 支持预览 |
| 设备信息 | 打卡设备信息 | 移动端信息 |

## 使用方法

### 提交移动打卡申请
1. 进入移动打卡申请页面
2. 点击「新增」按钮
3. 填写打卡日期、时间、类型
4. 选择打卡地点（移动端自动定位）
5. 填写申请理由
6. 提交申请

### 审批移动打卡申请
1. 切换到「审批人端」模式
2. 查看待审批列表
3. 点击申请记录查看详情
4. 选择「同意」或「拒绝」
5. 填写审批意见（可选）
6. 提交审批结果

### 查询打卡记录
1. 进入移动打卡记录页面
2. 设置筛选条件（员工、日期等）
3. 点击「查询」按钮
4. 查看打卡记录列表
5. 点击照片可预览打卡照片

## 注意事项

1. **权限控制**：申请人只能查看和操作自己的申请，审批人可以查看和处理所有申请
2. **照片存储**：打卡照片存储在文件服务器，需确保存储空间充足
3. **定位权限**：移动端需要获取GPS定位权限
4. **审批流程**：申请提交后进入审批流程，审批结果会通知申请人
5. **数据同步**：审批通过的打卡记录会同步到考勤统计中
