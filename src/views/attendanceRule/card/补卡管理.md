# 补卡申请模块

## 模块概述

本模块用于管理员工补卡申请，支持员工提交补卡申请、审批人审批补卡申请，以及补卡记录的查询和统计。补卡申请受补卡规则模块的限制。

## 核心功能

### 1. 补卡申请管理 (HrCardApplyList.vue)

#### 双模式切换
模块支持两种角色模式：
- **申请人端**：员工提交和管理自己的补卡申请
- **审批人端**：审批人员审核和处理补卡申请

#### 主要功能
- **申请列表**：查看补卡申请记录
- **新增申请**：提交新的补卡申请
- **审批处理**：审批人审核申请（同意/拒绝）
- **状态筛选**：按申请状态筛选（待审批、已同意、已拒绝）
- **数据导出**：导出申请记录为 Excel

#### 申请字段

| 字段名 | 说明 | 备注 |
|--------|------|------|
| 申请人 | 提交申请的员工 | 自动获取当前用户 |
| 申请时间 | 提交申请的时间 | 系统自动记录 |
| 补卡日期 | 申请补卡的日期 | 用户选择 |
| 补卡时间 | 申请补卡的具体时间 | 用户填写 |
| 补卡类型 | 上班补卡/下班补卡 | 用户选择 |
| 补卡原因 | 申请补卡的原因 | 用户填写 |
| 审批状态 | 待审批/已同意/已拒绝 | 系统状态 |
| 审批人 | 审批该申请的人员 | 系统记录 |
| 审批意见 | 审批人的审批意见 | 审批人填写 |

### 2. 补卡申请表 (HrBksqList.vue)

#### 主要功能
- **申请表列表**：查看所有补卡申请表记录
- **详情查看**：查看申请表详细信息
- **数据导出**：导出申请表数据为 Excel

## 使用方法

### 提交补卡申请
1. 进入补卡申请页面
2. 点击「新增」按钮
3. 填写补卡日期、时间、类型
4. 填写补卡原因
5. 提交申请

> **注意**：补卡申请受补卡规则限制，每月申请次数不能超过配置的最大次数，且需在规定时限内提交。

### 审批补卡申请
1. 切换到「审批人端」模式
2. 查看待审批列表
3. 点击申请记录查看详情
4. 选择「同意」或「拒绝」
5. 填写审批意见（可选）
6. 提交审批结果

### 查询申请记录
1. 进入补卡申请页面
2. 设置筛选条件（员工、日期、状态等）
3. 点击「查询」按钮
4. 查看申请记录列表

## 业务规则

### 补卡次数限制
- 员工每月补卡申请次数不能超过补卡规则配置的最大次数
- 超过限制后系统将不允许提交新的补卡申请

### 申请时限规则
- 补卡申请必须在补卡规则配置的时限内提交
- 超过时限的补卡申请将不予受理

### 审批流程
1. 员工提交补卡申请
2. 系统校验补卡规则（次数、时限）
3. 申请进入待审批状态
4. 审批人审核申请
5. 审批结果通知申请人
6. 审批通过的补卡记录同步到考勤统计

## 注意事项

1. **权限控制**：申请人只能查看和操作自己的申请，审批人可以查看和处理所有申请
2. **规则依赖**：补卡申请受 PCR 模块的补卡规则限制
3. **数据同步**：审批通过的补卡记录会同步到考勤统计中
4. **审批通知**：审批结果会通过系统消息通知申请人
5. **历史记录**：所有申请和审批记录都会保留，不可删除
