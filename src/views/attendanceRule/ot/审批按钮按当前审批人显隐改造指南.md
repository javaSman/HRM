# 审批按钮按当前审批人显隐改造指南

## 需求背景

在审批页「待审批」Tab 中，操作列的「审批」按钮需要根据**当前登录用户是否为该行当前审批节点的审批人之一**来动态显示/隐藏。
- 当前用户是审批人 → 显示「审批」按钮
- 当前用户不是审批人 → 隐藏「审批」按钮

## 适用模块

以下模块均需按此方案改造（加班申请已完成）：

## 改造步骤

每个模块的列表文件都需要做 **3 处改动**。

---

### 步骤 1：模板层 — 审批按钮增加 `v-if` 判断

找到操作列 slot 中「审批页 - 待审批」的模板，给「审批」按钮加上判断：

```vue
<!-- 改造前 -->
<template v-if="activeKey == 1 && boxState == 1">
  <a style="color: #ff5500;" @click="handleApprove(record)">审批</a>
</template>

<!-- 改造后 -->
<template v-if="activeKey == 1 && boxState == 1">
  <a v-if="isCurrentApprover(record)" style="color: #ff5500;" @click="handleApprove(record)">审批</a>
</template>
```

> 注意：只对「审批页的待审批」场景生效，其他 Tab（已审批、抄送我的）不需要改。

---

### 步骤 2：computed 中新增 `currentUser`

在 `computed` 对象中添加：

```js
// 当前登录用户信息
currentUser() {
  return this.$store.state.user.info || {}
},
```

---

### 步骤 3：methods 中新增 `isCurrentApprover` 方法

在 `methods` 中添加以下方法（建议放在状态标签相关方法之后，Tab 切换方法之前）：

```js
/**
 * 判断当前登录用户是否为该申请当前审批节点的审批人之一
 * 注意：sprId / sprName 可能是逗号分隔的多个人，需要拆分后匹配
 * 匹配优先级：sprId（用户ID） → 工号 → sprName（姓名）
 * @param {Object} record - 当前行数据
 * @returns {Boolean}
 */
isCurrentApprover(record) {
  const userInfo = this.currentUser
  if (!userInfo || !record) return false

  const spjdList = record.customProcessSqdSpjdList
  if (!spjdList || !Array.isArray(spjdList) || spjdList.length === 0) {
    return false
  }

  // 筛选出当前节点的审批人记录
  const currentNodeApprovers = spjdList.filter(item => item.nodeName == record.spFlow)
  if (currentNodeApprovers.length === 0) {
    return false
  }

  // 当前用户的各个标识
  const userId = String(userInfo.id || '').trim()
  const userNo = String(userInfo.username || userInfo.no || '').trim()
  const realname = (userInfo.realname || '').trim()

  // 遍历当前节点的每条审批人记录（每条里可能是逗号分隔的多人）
  for (const item of currentNodeApprovers) {
    // 1. 拆分 sprId 数组，逐个匹配用户ID
    if (userId && item.sprId) {
      const sprIdList = String(item.sprId).split(',').map(s => s.trim()).filter(Boolean)
      if (sprIdList.includes(userId)) {
        return true
      }
    }

    // 2. 拆分 sprId 数组，逐个匹配工号（抄送节点的 sprId 存的是工号）
    if (userNo && item.sprId) {
      const sprIdList = String(item.sprId).split(',').map(s => s.trim()).filter(Boolean)
      if (sprIdList.includes(userNo)) {
        return true
      }
    }

    // 3. 拆分 sprName 数组，逐个匹配姓名
    if (realname && item.sprName) {
      const sprNameList = String(item.sprName).split(',').map(s => s.trim()).filter(Boolean)
      if (sprNameList.includes(realname)) {
        return true
      }
    }
  }

  return false
},
```

## 判断逻辑说明

### 数据来源

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 当前用户信息 | `this.$store.state.user.info` | 包含 `id`、`realname`、`username` 等字段 |
| 审批节点列表 | `record.customProcessSqdSpjdList` | 数组，每个元素是一个审批节点 |
| 当前节点名称 | `record.spFlow` | 如 `部门审批`、`HR审批` 等 |
| 节点审批人姓名 | `item.sprName` | 节点对象中的审批人姓名字段 |
| 节点审批人ID | `item.sprId` | 节点对象中的审批人ID字段（优先使用） |

### 匹配规则

1. 先从 `customProcessSqdSpjdList` 中筛选出 `nodeName == spFlow` 的节点（即当前正在处理的审批节点）
2. 每个节点的 `sprId` / `sprName` 可能是**逗号分隔的多人**（会签/或签场景），需要先 `split(',')` 拆分成数组再匹配
3. 匹配优先级：
   - **用户ID匹配**：拆分 `sprId` 数组，判断是否包含 `userInfo.id`
   - **工号匹配**：拆分 `sprId` 数组，判断是否包含 `userInfo.username`（抄送节点的 sprId 存的是工号）
   - **姓名兜底匹配**：拆分 `sprName` 数组，判断是否包含 `userInfo.realname`
4. 任意一个审批人匹配成功即返回 `true`
5. 所有比较前都做 `trim()` 去除首尾空格，避免空格导致匹配失败
6. 数据缺失时安全返回 `false`（按钮隐藏，不影响其他功能）
