# 补卡规则配置模块

## 模块概述

本模块用于管理公司补卡规则配置，设置每月最大补卡申请次数、补卡申请时限等规则参数，为补卡申请模块提供规则依据。

## 文件结构

```
PCR/
├── HrBkRuleList.vue    # 补卡规则列表主页面
├── modules/
│   └── HrBkRuleModal.vue  # 补卡规则编辑弹窗
└── README.md            # 本文档
```

## 核心功能

### 1. 规则列表管理
- **列表展示**：展示所有补卡规则配置记录
- **搜索筛选**：支持按公司等条件筛选
- **数据导出**：支持导出规则配置数据为 Excel

### 2. 规则配置
- **新增规则**：添加新的补卡规则配置
- **编辑规则**：修改现有规则配置参数
- **删除规则**：删除不需要的规则配置
- **批量导入**：支持 Excel 批量导入规则数据

### 3. 关键配置字段

| 字段名 | 说明 | 备注 |
|--------|------|------|
| 公司名称 | 规则适用的公司 | 关联公司表 |
| 每月最大补卡次数 | 员工每月可申请的最大补卡次数 | 默认值建议：3次 |
| 补卡申请时限 | 补卡申请的时间限制 | 例如：3天内 |
| 规则状态 | 启用/禁用 | 控制规则是否生效 |
| 生效日期 | 规则开始生效的日期 | - |
| 失效日期 | 规则失效的日期 | 可选 |

## 使用方法

### 新增规则配置
1. 点击列表上方「新增」按钮
2. 在弹窗中填写规则配置信息
3. 选择适用公司
4. 设置每月最大补卡次数
5. 设置补卡申请时限
6. 选择规则状态（启用/禁用）
7. 点击「确定」保存

### 编辑规则
1. 在列表中找到目标记录
2. 点击操作列的「编辑」按钮
3. 在弹窗中修改配置参数
4. 点击「确定」保存修改

### 导入规则数据
1. 点击「导入」按钮
2. 下载导入模板
3. 按模板格式填写数据
4. 上传填好的 Excel 文件

## 业务规则

### 补卡次数限制
- 员工每月补卡申请次数不能超过配置的最大次数
- 超过限制后系统将不允许提交新的补卡申请

### 申请时限规则
- 补卡申请必须在规定的时限内提交
- 超过时限的补卡申请将不予受理

### 规则优先级
- 同一公司只能有一条启用的规则
- 新增规则时需检查是否已存在启用的规则

## 注意事项

1. **规则唯一性**：同一公司只能有一条启用的补卡规则
2. **数据完整性**：删除前请确认该规则未被补卡申请引用
3. **参数合理性**：补卡次数和时限需根据公司实际情况合理设置
4. **权限控制**：新增、编辑、删除操作需要相应权限
5. **规则生效**：只有启用状态的规则才会生效
