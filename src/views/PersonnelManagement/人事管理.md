# 人事管理模块

## 模块概述

人事管理模块包含人员管理和招聘管理两大核心功能，提供完整的人力资源管理解决方案。

## 目录结构

```
PersonnelManagement/
├── Personnel/              # 人员管理
│   ├── onboarding/         # 入职管理
│   └── 人员管理.md         # 人员管理文档
├── Recruitment/            # 招聘管理
│   ├── common/             # 公共组件
│   ├── interview/          # 面试管理
│   ├── offer/              # Offer管理
│   ├── overview/           # 招聘总览
│   ├── plan/               # 招聘计划
│   ├── resume/             # 简历管理
│   ├── yongren/            # 用人申请
│   ├── 招聘管理.md         # 招聘管理文档
│   └── mockStore.js        # Mock数据
└── 人事管理.md             # 本文档
```

## 核心功能

### 1. 人员管理

#### 入职管理 (`Personnel/onboarding`)
- **功能说明**：管理员工入职流程，包括资料审核、入职办理、合同签署等
- **columnCode**：`HrmJlgl`
- **主要状态**：
  - 待入职（pending）
  - 已入职（onboarded）
  - 放弃入职（abandoned）
- **核心操作**：
  - 入职办理
  - 资料审核
  - 取消入职
  - 调整入职时间
  - 确认到岗
  - 打印履历表
  - 合同签署

详见：[人员管理.md](./Personnel/人员管理.md)

### 2. 招聘管理

招聘管理包含以下子模块：

#### 招聘总览 (`Recruitment/overview`)
- **功能说明**：展示招聘整体数据统计和可视化图表
- **columnCode**：暂无字段配置
- **核心功能**：
  - 招聘数据统计
  - 各阶段数据可视化
  - 实时数据更新

详见：[招聘总览.md](./Recruitment/overview/招聘总览.md)

#### 招聘计划 (`Recruitment/plan`)
- **功能说明**：管理招聘计划的发起、审批和执行
- **columnCode**：`HrmZphgl`
- **主要状态**：
  - 待发布
  - 招聘中
  - 已完成
  - 已取消
  - 不通过
- **核心操作**：
  - 发起招聘计划
  - 审批招聘计划
  - 减少招聘人数
  - 取消招聘计划

详见：[招聘计划.md](./Recruitment/plan/招聘计划.md)

#### 用人申请 (`Recruitment/yongren`)
- **功能说明**：管理用人申请的发起、审批和执行
- **columnCode**：`HrmYrsgl`
- **主要状态**：
  - 审批中
  - 已通过
  - 招聘中
  - 已完成
  - 已取消
  - 已拒绝
- **核心操作**：
  - 发起用人申请
  - 审批用人申请
  - 再次申请
  - 取消申请

详见：[用人申请.md](./Recruitment/yongren/用人申请.md)

#### 简历管理 (`Recruitment/resume`)
- **功能说明**：管理候选人简历的筛选、邀约和状态流转
- **columnCode**：`HrmJlgl`
- **主要状态**：
  - 待分配
  - 待邀约
  - 已邀约
  - 已淘汰
- **核心操作**：
  - 简历筛选
  - 发起邀约
  - 分配面试官
  - 状态流转
- **特殊功能**：
  - 多状态列配置（不同状态显示不同列）

详见：[简历管理.md](./Recruitment/resume/简历管理.md)

#### 面试管理 (`Recruitment/interview`)
- **功能说明**：管理面试安排、面试过程和面试结果
- **columnCode**：`HrmMsgl`
- **主要状态**：
  - 待面试
  - 面试中
  - 面试通过
  - 已淘汰
  - 已发offer
- **核心操作**：
  - 新增面试
  - 开始初试
  - 改期
  - 安排部门复试
  - 发起Offer

详见：[面试管理.md](./Recruitment/interview/面试管理.md)

#### Offer管理 (`Recruitment/offer`)
- **功能说明**：管理Offer的发起、审批和确认

- **主要状态**：

  - 待确认
  - 已确认

- **核心操作**：
  - 发起Offer

详见：[offer管理.md](./Recruitment/offer/offer管理.md)

## 字段配置功能

所有列表页面均支持字段配置功能，用户可以自定义显示的列和列的顺序。

### 已集成字段配置的页面

| 模块 | 页面 | columnCode | 文档 |
|------|------|------------|------|
| 人员管理 | 入职管理 | `HrmJlgl` | [人员管理.md](./Personnel/人员管理.md) |
| 招聘管理 | 招聘计划 | `HrmZphgl` | [招聘计划.md](./Recruitment/plan/招聘计划.md) |
| 招聘管理 | 用人申请 | `HrmYrsgl` | [用人申请.md](./Recruitment/yongren/用人申请.md) |
| 招聘管理 | 简历管理 | `HrmJlgl` | [简历管理.md](./Recruitment/resume/简历管理.md) |
| 招聘管理 | 面试管理 | `HrmMsgl` | [面试管理.md](./Recruitment/interview/面试管理.md) |
| 招聘管理 | Offer管理 | `HrmOffergl` | [offer管理.md](./Recruitment/offer/offer管理.md) |

### 使用方法

1. 点击列表页右上角的"字段配置"按钮
2. 在侧边栏中选择需要显示的字段
3. 通过拖拽调整字段顺序
4. 点击"确认"保存配置

### 技术实现

- **通用Mixin**：使用 `columnConfigMixin.js` 提供字段配置能力
- **特殊Mixin**：简历管理使用 `resumeColumnsMixin.js` 支持多状态列配置
- **组件**：使用 `ColumnConfigSidebar.vue` 作为配置界面
- **API**：通过 `/hr_field_config/hrFieldConfig/...` 接口保存配置

详见：[字段配置使用指南](../../components/README.md)

## 数据流转

### 招聘流程数据流转图

```
用人申请 → 招聘计划 → 简历管理 → 面试管理 → Offer管理 → 入职管理
   ↓          ↓          ↓          ↓          ↓          ↓
 审批中     待发布     待分配     待面试     审批中     待入职
 已通过     招聘中     待邀约     面试中     待确认     已入职
 招聘中     已完成     已邀约     面试通过   已确认     放弃入职
 已完成     已取消     已淘汰     已淘汰     已拒绝
 已取消     不通过                已发offer
 已拒绝
```
