# 招聘总览

## 功能说明

展示招聘整体数据统计和可视化图表，提供招聘数据的实时监控和分析。

## 页面路径

`Recruitment/overview/index.vue`

## columnCode

暂无字段配置

## 核心功能

### 1. 数据统计

- 招聘计划总数
- 进行中招聘数
- 已完成招聘数
- 简历总数
- 面试总数
- Offer总数
- 入职总数

### 2. 数据可视化

- 招聘漏斗图
- 部门招聘分布
- 岗位招聘分布
- 时间趋势图

### 3. 实时更新

- 数据自动刷新
- 状态实时同步

## 核心方法

### 获取统计数据

```javascript
loadOverviewData() {
  this.loading = true
  Promise.all([
    this.getRecruitmentStats(),
    this.getDepartmentStats(),
    this.getPositionStats(),
    this.getTimeTrend()
  ]).then(() => {
    this.loading = false
  }).catch(() => {
    this.loading = false
  })
}
```

### 获取招聘统计

```javascript
getRecruitmentStats() {
  return httpAction('/zpManage/overview/stats', '', 'get').then(res => {
    if (res.success) {

}
```

## 数据刷新

### 自动刷新

```javascript
mounted() {
  this.loadOverviewData()
  // 每5分钟自动刷新
  this.timer = setInterval(() => {
    this.loadOverviewData()
  }, 5 * 60 * 1000)
},

beforeDestroy() {
  if (this.timer) {
    clearInterval(this.timer)
  }
}
```

### 手动刷新

```javascript
handleRefresh() {
  this.loadOverviewData()
  this.$message.success('数据已刷新')
}
```

## API接口

### 统计数据接口

```
GET /zpManage/overview/stats
```

**返回**：
```json
{
  "totalPlans": 100,
  "activePlans": 20,
  "completedPlans": 80,
  "totalResumes": 500,
  "totalInterviews": 200,
  "totalOffers": 50,
  "totalOnboarded": 30
}
```

### 部门统计接口

```
GET /zpManage/overview/department
```

**返回**：
```json
[
  {
    "department": "研发部",
    "plans": 10,
    "resumes": 100,
    "interviews": 50,
    "offers": 20,
    "onboarded": 10
  }
]
```

### 岗位统计接口

```
GET /zpManage/overview/position
```

**返回**：
```json
[
  {
    "position": "前端工程师",
    "headcount": 5,
    "resumes": 50,
    "interviews": 25,
    "offers": 10,
    "onboarded": 5
  }
]
```

### 时间趋势接口

```
GET /zpManage/overview/trend
```

**参数**：
- `type`: 趋势类型（day/week/month）

**返回**：
```json
[
  { "date": "2026-01", "count": 10 },
  { "date": "2026-02", "count": 15 }
]
```
