# 招聘管理

## 模块概述

招聘管理模块提供完整的招聘流程管理，包括招聘总览、招聘计划、用人申请、简历管理、面试管理和Offer管理等功能。

## 子模块

## 字段配置功能

所有列表页面均支持字段配置功能，用户可以自定义显示的列和列的顺序。

### 已集成字段配置的页面

| 页面 | columnCode | 文档 |
|------|------------|------|
| 招聘计划 | `HrmZphgl` | [招聘计划.md](./plan/招聘计划.md) |
| 用人申请 | `HrmYrsgl` | [用人申请.md](./yongren/用人申请.md) |
| 简历管理 | `HrmJlgl` | [简历管理.md](./resume/简历管理.md) |
| 面试管理 | `HrmMsgl` | [面试管理.md](./interview/面试管理.md) |
| Offer管理 | `HrmOffergl` | [offer管理.md](./offer/offer管理.md) |

### 使用方法

1. 点击列表页右上角的"字段配置"按钮
2. 在侧边栏中选择需要显示的字段
3. 通过拖拽调整字段顺序
4. 点击"确认"保存配置

### 技术实现

- **通用Mixin**：使用 `columnConfigMixin.js` 提供字段配置能力
- **特殊Mixin**：简历管理使用 `resumeColumnsMixin.js` 支持多状态列配置
- **组件**：使用 `ColumnConfigSidebar.vue` 作为配置界面
- **API**：通过 `/hr_field_config/hrFieldConfig/...` 接口保存配置

详见：[字段配置使用指南](../../components/README.md)

## 数据流转

### 招聘流程数据流转图

```
用人申请 → 招聘计划 → 简历管理 → 面试管理 → Offer管理 → 入职管理
   ↓          ↓          ↓          ↓          ↓          ↓
 审批中     待发布     待分配     待面试     审批中     待入职
 已通过     招聘中     待邀约     面试中     待确认     已入职
 招聘中     已完成     已邀约     面试通过   已确认     放弃入职
 已完成     已取消     已淘汰     已淘汰     已拒绝
 已取消     不通过                已发offer
 已拒绝
```

### 状态转换说明

#### 用人申请状态

- **审批中 → 已通过**：审批通过
- **审批中 → 已拒绝**：审批拒绝
- **已通过 → 招聘中**：开始招聘
- **招聘中 → 已完成**：招聘完成
- **任意状态 → 已取消**：取消申请

#### 招聘计划状态

- **待发布 → 招聘中**：审批通过
- **待发布 → 不通过**：审批拒绝
- **招聘中 → 已完成**：招聘完成
- **招聘中/待发布 → 已取消**：取消计划

#### 简历管理状态

- **待分配 → 待邀约**：分配面试官
- **待邀约 → 已邀约**：发起邀约
- **任意状态 → 已淘汰**：淘汰简历

#### 面试管理状态

- **待面试 → 面试中**：开始面试
- **面试中 → 面试通过**：面试通过
- **面试中 → 已淘汰**：面试淘汰
- **面试通过 → 已发offer**：发起Offer

#### Offer管理状态

- **审批中 → 待确认**：审批通过
- **审批中 → 审批拒绝**：审批拒绝
- **待确认 → 已确认**：候选人确认
- **待确认 → 已拒绝**：候选人拒绝
