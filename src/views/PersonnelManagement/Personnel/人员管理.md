# 人员管理

## 模块概述

人员管理模块负责管理员工入职流程，包括入职办理、资料审核、合同签署等功能。

```

│       ├── OnboardingDetailModal.vue        # 入职详情

│       └── OnboardingArrivalModal.vue       # 确认到岗

```

#### 资料审核

```javascript
handleReview(record) {
  this.$refs.reviewModal.open(record)
}

handleReviewOk({ action, record, comment }) {
  const target = this.mockOnboardData.find(item => item.id === record.id)
  if (!target) return
  
  target.reviewStatus = action === 'approve' ? 'passed' : 'rejected'
  target.reviewComment = comment
  this.$message.success(action === 'approve' ? '资料审核已通过' : '资料审核已驳回')
  this.loadData()
}
```

#### 取消入职

```javascript
handleCancelOnboard(record) {
  this.$refs.cancelModal.open(record)
}

handleCancelOk({ record, reason }) {
  const target = this.mockOnboardData.find(item => item.id === record.id)
  if (!target) return
  
  target.status = 'abandoned'
  target.abandonReason = reason
  target.actualDate = '-'
  this.$message.info('已取消入职，状态同步至放弃入职')
  this.loadData()
  this.onClearSelected()
}
```

#### 确认到岗

```javascript
handleConfirmArrival(record) {
  this.$refs.arrivalModal.open(record)
}

handleArrivalOk(payload) {
  const target = this.mockOnboardData.find(item => item.id === payload.record.id)
  if (!target) return
  
  target.status = 'onboarded'
  target.actualDate = getTodayDate()
  target.contractStatus = 'signed'
  target.contractForm = payload.contractForm
  target.contractStart = payload.contractStart
  target.contractEnd = payload.contractEnd
  target.probationStart = payload.probationStart
  target.probationEnd = payload.probationEnd
  this.$message.success('已确认到岗')
  this.loadData()
  this.onClearSelected()
}
```

#### 合同签署

```javascript
handleSignContract(record) {
  this.$confirm({
    title: '确认合同签署',
    content: `确认将「${record.name}」的合同状态标记为已签署？`,
    okText: '确认签署',
    cancelText: '暂不处理',
    onOk: () => {
      const target = this.mockOnboardData.find(item => item.id === record.id)
      if (target) {
        target.contractStatus = 'signed'
        this.$message.success(`「${record.name}」合同已签署`)
        this.loadData()
      }
    }
  })
}
```

## 数据流转

### 入职流程

```
发起入职 → 待入职 → 资料审核 → 确认到岗 → 已入职 → 合同签署
   ↓          ↓          ↓          ↓          ↓          ↓
 入职办理   审核中     已通过     实际入职    已入职    已签署
           未提交     已驳回                        未签署
                     待签署
```

### 状态转换

- **待入职 → 已入职**：确认到岗
- **待入职 → 放弃入职**：取消入职
- **已入职**：可进行合同签署操作
