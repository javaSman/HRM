# 访谈配置模块 (Interview Configuration Management)

## 📋 模块概述

访谈配置模块用于管理企业各类访谈模板的配置,支持入职、离职、日常等多种访谈类型,提供问题列表管理和事件记录追踪功能,为 HR 访谈工作提供标准化的配置管理工具。

## 📁 目录结构

```
interviewConfig/
├── index.vue                           # 主列表页面
├── interviewConfig.less                # 列表页样式文件
├── 访谈配置.md                          # 原有文档(空)
└── modules/
    ├── HrmFtpzModal.vue                # 新增/编辑模态框
    ├── HrmFtpzModal.Style#Drawer.vue   # 抽屉样式模态框(备用)
    ├── HrmFtpzForm.vue                 # 访谈配置表单组件
    └── HrmFtpzDetailModal.vue          # 访谈配置详情模态框
```

## 🎯 功能特性

### 1. 访谈配置列表

- 支持分页展示访谈配置记录
- 多维度筛选查询（访谈类型、所属种类、适用职级）
- 状态标签可视化展示
- 批量删除操作支持
- 快速启用/禁用切换

### 2. 状态管理

支持 3 种状态:

- **全部**: 显示所有访谈配置
- **启用**: 绿色标签 (#55c42a)
- **禁用**: 灰色标签 (#909399)

### 3. 访谈类型配置

#### 所属种类

系统支持 3 种访谈种类:

- **入职**: 新员工入职访谈
- **离职**: 员工离职访谈
- **日常**: 日常工作访谈

#### 适用职级

支持 2 种职级分类:

- **管理**: 管理层访谈配置
- **其他**: 其他职级访谈配置

### 4. 问题列表管理

- 支持动态添加问题
- 支持删除问题
- 问题内容编辑
- 跟进人设置
- 实时保存变更

### 5. 事件记录追踪

- 自动记录配置修改历史
- 记录修改人、修改内容、修改时间
- 支持查看完整变更记录

### 6. 字段配置

- 支持自定义列表字段显示
- 可配置字段显示/隐藏
- 字段配置标识: `HrmFtpz`

### HrmFtpzForm.vue (访谈配置表单)

**表单字段:**

- 状态（启用/禁用）
- 访谈类型（必填）
- 所属种类（必填）
- 适用职级（必填）

**问题列表字段（编辑模式显示）:**

- 序号（自动生成）
- 问题内容（必填）
- 跟进人（可选）

**功能特性:**

1. **新增模式**

   - 填写基本配置信息
   - 自动设置创建人为当前登录用户
   - 提交后跳转到编辑模式添加问题

2. **编辑模式**
   - 加载完整配置信息和问题列表
   - 支持动态添加问题
   - 支持删除问题（新增项直接删除，已保存项调用接口删除）
   - 自动检测问题列表变更
   - 变更时自动记录事件

**API 接口:**

- 新增: `/ryManage/hrmFtpz/add`
- 编辑: `/ryManage/hrmFtpz/edit`
- 编辑（含问题列表）: `/ryManage/hrmFtpz/editAll`
- 查询详情: `/ryManage/hrmFtpz/queryById`
- 查询完整详情: `/ryManage/hrmFtpz/queryDetlById`
- 删除问题: `/ryManage/hrmFtpzWtlb/delete`
- 新增事件记录: `/ryManage/hrmFtpzSjjl/add`

**变更检测逻辑:**

```javascript
hasWtlbListChanged() {
  // 检查是否有新增项
  const hasNewItems = this.model.wtlbList.some(item => !item.id || item.id === '');

  // 检查数量是否变化
  if (this.model.wtlbList.length !== this.originalWtlbList.length) {
    return true;
  }

  // 检查内容是否修改
  for (let i = 0; i < this.model.wtlbList.length; i++) {
    const current = this.model.wtlbList[i];
    const original = this.originalWtlbList.find(item => item.id === current.id);

    if (!original || current.wtnr !== original.wtnr || current.gjr !== original.gjr) {
      return true;
    }
  }

  return hasNewItems;
}
```

## 📊 数据流程

### 新增访谈配置流程

```
1. 点击"新增"按钮
   ↓
2. 打开 HrmFtpzModal
   ↓
3. 填写基本信息（状态、访谈类型、所属种类、适用职级）
   ↓
4. 提交表单（POST /ryManage/hrmFtpz/add）
   ↓
5. 自动设置创建人为当前用户
   ↓
6. 保存成功后跳转到编辑模式
```

### 编辑访谈配置流程

```
1. 点击"编辑"按钮
   ↓
2. 打开 HrmFtpzModal
   ↓
3. 加载配置信息和问题列表（GET /ryManage/hrmFtpz/queryDetlById）
   ↓
4. 修改基本信息或问题列表
   ↓
5. 提交表单（PUT /ryManage/hrmFtpz/editAll）
   ↓
6. 检测问题列表是否有变更
   ↓
7. 如有变更，自动记录事件（POST /ryManage/hrmFtpzSjjl/add）
```

### 问题管理流程

```
添加问题:
1. 点击"添加问题"按钮
   ↓
2. 新增空白问题行
   ↓
3. 填写问题内容和跟进人
   ↓
4. 提交时自动保存

删除问题:
1. 点击"删除"按钮
   ↓
2. 确认删除提示
   ↓
3. 如是新增项: 直接从数组移除
   如是已保存项: 调用删除接口 (DELETE /ryManage/hrmFtpzWtlb/delete)
   ↓
4. 记录事件（POST /ryManage/hrmFtpzSjjl/add）
```

### 状态切换流程

```
1. 点击"启用/禁用"按钮
   ↓
2. 弹出二次确认提示
   ↓
3. 确认后调用编辑接口（PUT /ryManage/hrmFtpz/edit）
   ↓
4. 更新状态
   ↓
5. 刷新列表和统计数据
```

## 📝 注意事项

1. **表单验证**

   - 访谈类型必填
   - 所属种类必填
   - 适用职级必填
   - 问题内容在添加问题时必填

2. **数据联动**

   - 新增配置后自动跳转到编辑模式
   - 删除问题时自动同步原始数据
   - 问题列表变更自动记录事件

3. **状态管理**

   - 启用/禁用切换带二次确认
   - 状态切换立即生效，无需刷新页面
   - 统计数据自动更新

4. **事件记录**

   - 仅在问题列表有变更时记录事件
   - 事件记录包含：修改人、修改内容、修改时间
   - 修改内容统一为"更新问题列表"

5. **字段配置**

   - 使用 `columnCode: 'HrmFtpz'` 作为字段配置标识
   - 配置保存后会影响列表显示的字段

6. **数据完整性**
   - 编辑时加载完整数据（包含问题列表）
   - 删除问题时检查是否已保存
   - 新增问题项 id 为空，保存后自动生成
