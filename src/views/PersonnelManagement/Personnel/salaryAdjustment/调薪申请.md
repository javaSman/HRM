# 薪资调整模块 (Salary Adjustment Management)

## 📋 模块概述

薪资调整模块用于管理企业员工薪资调整申请、审批流程,支持多种调薪类型,提供完整的薪资变更记录和审批流程管理。

## 📁 目录结构

```
salaryAdjustment/
├── index.vue                           # 主列表页面
├── HrmTxsqList.less                    # 列表页样式文件
└── modules/
    ├── HrmTxsqModal.vue                # 发起调薪模态框
    ├── HrmTxsqForm.vue                 # 调薪申请表单组件
    ├── HrmTxsqDetailModal.vue          # 调薪详情模态框
    └── HrmTxsqApproveModal.vue         # 调薪审批模态框
```

## 🎯 功能特性

### 1. 薪资调整记录列表

- 支持分页展示薪资调整记录
- 多维度筛选查询（工号、姓名、调薪类型、申请人、申请时间范围）
- 状态标签可视化展示
- 批量删除操作支持

### 2. 状态管理

支持 4 种状态流转:

- **全部**: 显示所有薪资调整记录
- **审批中**: 橙色标签 (#e6a23c)
- **通过**: 绿色标签 (#55c42a)
- **不通过**: 红色标签 (#f56c6c)

### 3. 调薪类型

系统支持以下 5 种调薪类型:

- **试用期结束调薪**: 员工试用期结束后的薪资调整
- **技能调薪**: 因技能提升进行的薪资调整
- **升职**: 因职位晋升进行的薪资调整
- **降职**: 因职位降低进行的薪资调整
- **其他**: 其他原因的薪资调整

### 4. 审批流程

- 支持多审批人选择
- 支持抄送人配置
- 审批结果可选（通过/不通过）
- 审批意见可选填
- 实时更新状态统计

### 5. 字段配置

- 支持自定义列表字段显示
- 可配置字段显示/隐藏
- 字段配置标识: `HrmTxsq`

## 🔧 核心组件说明

### index.vue (主列表页面)

**主要功能:**

- 状态筛选 Tab 切换
- 多条件搜索筛选
- 数据列表展示
- 操作按钮（详情、审批）

**关键数据:**

- 批量删除: `/ryManage/hrmTxsq/deleteBatch`
- 状态统计: `/ryManage/hrmTxsq/getTotal`

**列表字段:**
| 字段名 | 显示名称 | 说明 |
|--------|---------|------|
| zt | 状态 | 带颜色标签显示 |

| xm | 姓名 | 员工姓名 |
| txqxz | 调薪前薪资(k) | 调整前薪资 |

| txlx | 调薪类型 | 调薪原因分类 |
| txyy | 调薪原因 | 具体调薪原因说明 |
| sxrq | 生效日期 | 薪资调整生效日期 |
| sqr | 申请人 | 发起申请人员 |

### HrmTxsqForm.vue (调薪申请表单)

**表单字段:**

- 调薪人员（必填,支持搜索选择）
- 调薪类型（必填）
- 调薪后薪资（必填,单位: k,支持小数点后两位）
- 生效日期（必填,建议选择次月之后）
- 调薪原因（必填,最多 500 字）
- 审批人（必填,支持多选）
- 抄送人（可选,支持多选）

**自动填充逻辑:**
选择调薪人员后自动填充:

- 工号
- 姓名
- 公司
- 所属部门
- 岗位名称
- 调薪前薪资

**API 接口:**

- 新增: `/ryManage/hrmTxsq/add`
- 编辑: `/ryManage/hrmTxsq/edit`
- 查询详情: `/ryManage/hrmTxsq/queryById`

**表单验证规则:**

```javascript
validatorRules: {
  txrq: [{ required: true, message: '请选择调薪人员!', trigger: 'change' }],
  txlx: [{ required: true, message: '请选择调薪类型!', trigger: 'change' }],
  txhxz: [{ required: true, message: '请输入调薪后薪资!', trigger: 'blur' }],
  sxrq: [{ required: true, message: '请选择生效日期!', trigger: 'change' }],
  txyy: [{ required: true, message: '请输入调薪原因!', trigger: 'blur' }],
}
```

**提交逻辑:**

- 自动设置状态为"审批中"
- 自动设置申请人为当前登录用户
- 自动设置申请时间为当前日期

### HrmTxsqApproveModal.vue (审批模态框)

**功能:**

- 展示调薪申请基本信息
- 选择审批结果（通过/不通过）
- 填写审批意见（可选）
- 提交审批结果

**展示信息:**

- 工号
- 姓名
- 调薪类型
- 调薪前薪资
- 调薪后薪资
- 生效日期
- 调薪原因

**API 接口:**

- 审批: `/ryManage/hrmTxsq/approve`

**审批结果:**

- 通过: 更新状态为"通过"
- 不通过: 更新状态为"不通过"

### HrmTxsqDetailModal.vue (详情模态框)

**功能:**

- 查看薪资调整完整信息
- 薪资前后对比展示
- 审批流程展示

**展示内容:**

1. **顶部状态条**

   - 调薪类型
   - 当前状态（带颜色）
   - 生效日期

2. **基本信息表格**

   - 公司、所属部门
   - 岗位名称、调薪类型
   - 调薪前薪资（红色标注）
   - 调薪后薪资（绿色标注）
   - 生效日期、申请时间
   - 申请人、抄送人

3. **调薪原因**

   - 独立区块展示

4. **审批流程**
   - 时间轴展示审批进度

**API 接口:**

- 查询详情: `/ryManage/hrmTxsq/queryById`

## 📊 数据流程

### 发起调薪流程

```
1. 点击"发起调薪"按钮
   ↓
2. 打开 HrmTxsqModal
   ↓
3. 选择调薪人员（自动加载基本信息和原薪资）
   ↓
4. 选择调薪类型
   ↓
5. 输入调薪后薪资
   ↓
6. 选择生效日期（建议次月之后）
   ↓
7. 填写调薪原因
   ↓
8. 选择审批人和抄送人
   ↓
9. 提交表单（POST /ryManage/hrmTxsq/add）
   ↓
10. 状态设置为"审批中"
```

### 审批流程

```
1. 审批人收到待办
   ↓
2. 打开 HrmTxsqApproveModal
   ↓
3. 查看调薪信息
   ↓
4. 选择审批结果（通过/不通过）
   ↓
5. 填写审批意见（可选）
   ↓
6. 提交审批（POST /ryManage/hrmTxsq/approve）
   ↓
7. 更新状态为"通过"或"不通过"
```

## 🔒 权限控制

- **操作权限**: 根据用户角色控制审批操作
- **数据权限**: 根据用户部门过滤可查看的调薪记录
- **状态权限**: "审批中"状态才显示审批按钮

## 📝 注意事项

1. **表单验证**

   - 调薪人员必选
   - 调薪类型必选
   - 调薪后薪资必填（数字,支持小数点后两位）
   - 生效日期必填
   - 调薪原因必填（最多 500 字）
   - 审批人必选（支持多选）

2. **数据联动**

   - 选择调薪人员 → 自动填充基本信息和原薪资
   - 审批人/抄送人自动拼接为逗号分隔的姓名字符串

3. **状态流转**

   - 审批中 → 通过 / 不通过
   - 其他状态为终态,不可逆转

4. **生效日期提示**

   - 系统提示"调薪生效时间应该选择次月之后"
   - 确保薪资调整在正确的薪酬周期生效

5. **薪资显示**

   - 列表和详情中薪资单位为"k"（千）
   - 调薪前后薪资用不同颜色区分

6. **字段配置**
   - 使用 `columnCode: 'HrmTxsq'` 作为字段配置标识
   - 配置保存后会影响列表显示的字段
