# 访谈问题跟进模块 (Interview Follow-up Management)

## 📋 模块概述

访谈问题跟进模块用于管理企业访谈后续问题的跟进处理,基于访谈配置模板发起的访谈记录进行问题跟踪和解决,支持跟进状态管理和附件上传,为 HR 提供完整的访谈问题闭环管理工具。

## 📁 目录结构

```
interviewFollow/
├── index.vue                           # 主列表页面
├── index.less                          # 列表页样式文件
└── modules/
    ├── DetailModal.vue                 # 访谈详情模态框
    ├── FollowModal.vue                 # 跟进填写模态框
    └── HrmFtwtkjForm.vue               # 基础表单组件(备用)
```

## 🎯 功能特性

### 1. 访谈问题跟进列表

- 支持分页展示访谈问题记录
- 多维度筛选查询（所属种类、适用职级、姓名）
- 跟进状态可视化展示
- 字段自定义配置

### 2. 状态管理

支持 3 种状态:

- **全部**: 显示所有访谈问题记录
- **跟进中**: 橙色标签 (#e6a23c)
- **已完成**: 绿色标签 (#67c23a)

### 3. 访谈问题分类

#### 所属种类

系统支持 3 种访谈种类:

- **入职**: 新员工入职访谈问题
- **离职**: 员工离职访谈问题
- **日常**: 日常工作访谈问题

#### 适用职级

支持 2 种职级分类:

- **管理**: 管理层访谈问题
- **其他**: 其他职级访谈问题

### 4. 跟进管理

- 填写跟进描述（必填）
- 上传附件（可选）
- 自动记录跟进时间
- 自动更新状态为"已完成"

### 5. 详情查看

- 查看员工基本信息
- 查看访谈详细信息
- 查看跟进记录
- 查看跟进附件

### 6. 字段配置

- 支持自定义列表字段显示
- 可配置字段显示/隐藏
- 字段配置标识: `HrmFtwtkj`

- 认证方式: X-Access-Token

**API 接口:**

- 编辑: `/ryManage/hrmFtwtkj/edit`

**提交逻辑:**

```javascript

  gjms: this.model.gjms, // 跟进描述
```

## 📊 数据流程

### 访谈问题列表查看流程

```
1. 访谈配置模块创建访谈模板
   ↓
2. HR 执行访谈并记录访谈问题
   ↓
3. 系统生成访谈问题跟进记录
   ↓
4. 访谈问题跟进模块展示待跟进问题列表
   ↓
5. 状态筛选：全部 / 跟进中 / 已完成
```

### 问题跟进处理流程

```
1. 查看待跟进问题列表
   ↓
2. 点击"详情"查看完整信息
   ↓
3. 确认需要跟进的问题
   ↓
4. 点击"跟进"按钮（仅"跟进中"状态可用）
   ↓
5. 打开 FollowModal
   ↓
6. 填写跟进描述（必填）
   ↓
7. 上传附件（可选）
   ↓
8. 提交跟进记录（POST /ryManage/hrmFtwtkj/edit）
   ↓
9. 自动更新状态为"已完成"
   ↓
10. 自动记录跟进时间为当前日期
```

### 附件上传流程

```
1. 点击上传区域
   ↓
2. 选择文件（限制 10MB 以内）
   ↓
3. 上传到服务器（POST /sys/common/upload）
   ↓
4. 获取文件路径
   ↓
5. 提交时附带文件路径
```

## 🔒 权限控制

- **查看权限**: 所有用户均可查看访谈问题列表和详情
- **跟进权限**: 根据用户角色控制跟进操作
- **状态权限**: 仅"跟进中"状态显示跟进按钮

## 📝 注意事项

1. **状态管理**

   - 初始状态为"跟进中"
   - 跟进后自动更新为"已完成"
   - 状态不可逆转

2. **跟进描述**

   - 跟进描述为必填项
   - 最多可输入 500 字
   - 支持多行文本

3. **附件上传**

   - 单次只能上传 1 个附件
   - 文件大小限制 10MB
   - 支持常见格式
   - 上传失败会清空文件列表

4. **跟进时间**

   - 自动记录为提交当天的日期
   - 格式: YYYY-MM-DD
   - 无需手动填写

5. **字段配置**

   - 使用 `columnCode: 'HrmFtwtkj'` 作为字段配置标识
   - 配置保存后会影响列表显示的字段

6. **数据来源**
   - 访谈问题记录由访谈配置模块生成
   - 本模块仅负责跟进处理
   - 不支持新增访谈问题记录

## 🔍 与访谈配置的关系

### 数据流向

```
访谈配置模块
   ↓
创建访谈模板 + 问题列表
   ↓
HR 执行访谈
   ↓
生成访谈问题记录
   ↓
访谈问题跟进模块
   ↓
跟进处理 → 完成
```

| 访谈类型 | ftlx         | 继承自访谈配置 |
| 所属种类 | sszl         | 继承自访谈配置 |
| 适用职级 | syzj         | 继承自访谈配置 |

## 📊 典型应用场景

### 场景 1: 新员工入职访谈问题跟进

```
1. 新员工入职后进行访谈
   ↓
2. 发现工作适应问题
   ↓
3. 系统生成问题跟进记录
   - 所属种类: 入职
   - 问题内容: 对工作流程不熟悉
   - 跟进人: 部门主管
   - 状态: 跟进中
   ↓
4. 部门主管跟进处理
   - 安排培训
   - 指定导师辅导
   - 上传培训计划附件
   ↓
5. 提交跟进记录
   - 状态更新: 已完成
   - 跟进时间: 2024-01-15
```

### 场景 2: 员工离职访谈问题跟进

```
1. 员工提出离职后进行访谈
   ↓
2. 了解离职原因和工作建议
   ↓
3. 系统生成问题跟进记录
   - 所属种类: 离职
   - 问题内容: 薪资待遇问题
   - 跟进人: HR
   - 状态: 跟进中
   ↓
4. HR 跟进处理
   - 记录薪资调研结果
   - 制定薪资调整方案
   - 上传调研报告附件
   ↓
5. 提交跟进记录
   - 状态更新: 已完成
   - 跟进时间: 2024-01-20
```

### 场景 3: 日常工作访谈问题跟进

```
1. 定期与员工进行工作访谈
   ↓
2. 了解工作进展和困难
   ↓
3. 系统生成问题跟进记录
   - 所属种类: 日常
   - 问题内容: 项目进度延迟
   - 跟进人: 项目经理
   - 状态: 跟进中
   ↓
4. 项目经理跟进处理
   - 协调资源支持
   - 调整项目计划
   - 上传调整方案附件
   ↓
5. 提交跟进记录
   - 状态更新: 已完成
   - 跟进时间: 2024-01-25
```
