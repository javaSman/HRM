# 调动管理模块 (Personnel Mobilize Management)

## 📋 模块概述

调动管理模块用于处理企业内部人员的人事调动业务,包括调岗、晋升、降职三种类型,支持完整的审批流程和状态管理。

## 📁 目录结构

```
mobilize/
├── HrmTdglList.vue                    # 主列表页面
├── HrmTdglList.less                   # 列表页样式文件
└── modules/
    ├── HrmTdglModal.vue               # 发起调动模态框
    ├── HrmTdglModal.Style#Drawer.vue  # 抽屉样式模态框(备用)
    ├── HrmTdglForm.vue                # 调动表单组件
    ├── HrmTdglDetailModal.vue         # 调动详情模态框
    ├── HrmTdglDetailModal.less        # 详情模态框样式
    ├── HrmTdglApproveModal.vue        # 调动审批模态框
    └── HrmTdglCancelModal.vue         # 取消调动模态框
```

## 🎯 功能特性

### 1. 调动记录列表

- 支持分页展示调动记录
- 多维度筛选查询(工号、姓名、调动类型)
- 状态标签可视化展示
- 批量操作支持

### 2. 状态管理

支持 6 种状态流转:

- **全部**: 显示所有调动记录
- **审批中**: 橙色标签 (#e6a23c)
- **已通过**: 绿色标签 (#55c42a)
- **已拒绝**: 红色标签 (#f56c6c)
- **已取消**: 灰色标签 (#909399)
- **调动完成**: 深绿色标签 (#67c23a)

### 3. 调动类型

#### 调岗

- 需选择调动后公司、部门、岗位、职级
- 支持组织架构级联选择
- 自动加载对应岗位和职级选项

#### 晋升

- 仅需选择调动后职级
- 公司、部门、岗位自动继承原值
- 自动加载当前岗位的职级选项

#### 降职

- 仅需选择调动后职级
- 公司、部门、岗位自动继承原值
- 自动加载当前岗位的职级选项

### 4. 审批流程

- 支持用户会签(多审批人)
- 支持抄送人配置
- 审批意见必填
- 可同意或拒绝调动申请

### 5. 字段配置

- 支持自定义列表字段显示
- 可配置字段显示/隐藏
- 字段顺序可调整

## 🔧 核心组件说明

### HrmTdglList.vue (主列表页面)

**主要功能:**

- 状态筛选 Tab 切换
- 搜索条件筛选
- 数据列表展示
- 操作按钮(详情、审批、取消)
- 字段配置侧边栏

**关键数据:**

```javascript
statusOptions: [
  { label: '全部', value: '全部', code: 'all', count: 0 },
  { label: '审批中', value: '审批中', code: 'pending', count: 0 },
  { label: '已通过', value: '已通过', code: 'approved', count: 0 },
  { label: '已拒绝', value: '已拒绝', code: 'rejected', count: 0 },
  { label: '已取消', value: '已取消', code: 'cancelled', count: 0 },
  { label: '调动完成', value: '调动完成', code: 'completed', count: 0 },
]
```

**API 接口:**

- 列表查询: `/ryManage/hrmTdgl/list`
- 删除: `/ryManage/hrmTdgl/delete`
- 批量删除: `/ryManage/hrmTdgl/deleteBatch`
- 状态统计: `/ryManage/hrmTdgl/getTotal`
- 导出: `/ryManage/hrmTdgl/exportXls`
- 导入: `ryManage/hrmTdgl/importExcel`

### HrmTdglForm.vue (调动表单)

**表单字段:**

- 调动人员(必填)
- 调动类型(必填,默认"调岗")
- 调动后公司(调岗必填)
- 调动后部门(调岗必填)
- 调动后岗位(调岗必填)
- 调动后职级(晋升/降职必填)
- 调动生效时间(必填)
- 调动原因
- 审批人(必填,支持会签)
- 抄送人

**联动逻辑:**

1. 选择调动人员 → 自动填充原公司、原部门、原岗位、原职级
2. 选择调动类型 → 清空调动后字段
3. 选择公司 → 加载部门选项
4. 选择部门 → 加载岗位选项
5. 选择岗位 → 加载职级选项

**API 接口:**

- 新增: `/ryManage/hrmTdgl/add`
- 编辑: `/ryManage/hrmTdgl/edit`
- 查询详情: `/ryManage/hrmTdgl/queryById`
- 员工信息: `/hrEmployee/hrEmployee/queryById`
- 组织架构树: `/org/hrmOrg/loadTreeRoot`
- 岗位列表: `/hrJobSequence/hrJobSequence/getChildSequences`

### HrmTdglApproveModal.vue (审批模态框)

**功能:**

- 显示调动基本信息(发起人、姓名、调动类型、调动原因)
- 审批意见输入(必填)
- 同意/拒绝操作
- 更新状态为"已通过"或"已拒绝"

**API 接口:**

- 审批: `/ryManage/hrmTdgl/approve`

### HrmTdglCancelModal.vue (取消模态框)

**功能:**

- 显示调动基本信息
- 取消原因输入(必填)
- 确认取消操作
- 更新状态为"已取消"

**API 接口:**

- 编辑: `/ryManage/hrmTdgl/edit`

### HrmTdglDetailModal.vue (详情模态框)

**功能:**

- 基本信息展示(调动前后对比表格)
- 审批流程时间轴展示
- Tab 切换(基本信息/审批流程)

**特色:**

- 表格化对比展示调动前后信息
- 时间轴展示审批流程状态
- 支持不同状态的可视化标识

## 📊 数据流程

### 发起调动流程

```
1. 点击"发起调动"按钮
   ↓
2. 打开 HrmTdglModal
   ↓
3. 选择调动人员(加载原信息)
   ↓
4. 选择调动类型
   ↓
5. 填写调动后信息(根据类型显示不同字段)
   ↓
6. 选择审批人和抄送人
   ↓
7. 提交表单(POST /ryManage/hrmTdgl/add)
   ↓
8. 状态设置为"审批中"
```

### 审批流程

```
1. 审批人收到待办
   ↓
2. 打开 HrmTdglApproveModal
   ↓
3. 查看调动信息并填写审批意见
   ↓
4. 同意/拒绝(POST /ryManage/hrmTdgl/approve)
   ↓
5. 更新状态为"已通过"或"已拒绝"
```

## 🔒 权限控制

- 操作权限: 根据用户角色控制审批、取消等操作
- 数据权限: 根据用户部门过滤可查看的调动记录
- 状态权限: "审批中"状态才显示审批和取消按钮

## 📝 注意事项

1. **表单验证**

   - 调动人员必选
   - 调动类型必选
   - 调动生效时间必填
   - 审批人必填(支持会签)
   - 根据调动类型动态验证必填字段

2. **数据联动**

   - 公司 → 部门 → 岗位 → 职级 级联选择
   - 晋升/降职自动继承原公司、部门、岗位

3. **状态流转**

   - 审批中 → 已通过 / 已拒绝 / 已取消
   - 已通过 → 调动完成(需要后续处理)
   - 其他状态为终态,不可逆转

4. **字段配置**
   - 使用 `columnCode: 'HrmTdgl'` 作为字段配置标识
   - 配置保存后会影响列表显示的字段
