# 试用期跟踪模块 (Probation Period Tracking Management)

## 📋 模块概述

试用期跟踪模块用于管理企业新员工试用期全流程,包括试用期员工信息管理、访谈记录添加、转正申请发起等功能,支持多维度查询和详细的员工信息展示,为 HR 提供完整的试用期员工管理解决方案。

## 🎯 功能特性

### 1. 试用期员工列表

- 支持分页展示试用期员工记录
- 多维度筛选查询（公司、部门、岗位、工号、姓名、试用期时间范围）
- 状态标签可视化展示
- 批量操作支持
- 导入导出功能

### 2. 状态管理

支持 4 种状态:

- **全部**: 显示所有试用期员工记录
- **试用期**: 灰色标签 (#909399) - 试用期进行中
- **未转正**: 橙色标签 (#e6a23c) - 已发起转正申请,待审批
- **拒绝转正**: 红色标签 (#f56c6c) - 转正申请被拒绝

### 3. 核心操作功能

#### 添加访谈

- 选择访谈日期
- 选择适用职级（管理/其他）
- 选择访谈类型（自动加载问题列表）
- 填写访谈情况和问题标记
- 支持两种模式：试用期访谈 / 日常访谈

#### 发起转正

- 自动显示员工基本信息
- 选择计划转正日期
- 填写转正意见说明
- 选择审批人和抄送人
- 提交转正申请

#### 查看详情

- 员工基本信息展示
- 教育经历列表
- 工作履历列表
- 家庭成员列表
- 个人附件列表
- 关系申报列表
- 访谈经历记录

### 4. 字段配置

- 支持自定义列表字段显示
- 可配置字段显示/隐藏
- 字段配置标识: `HrmSyqgz`

### 5. 组织架构联动

- 公司 → 部门 → 岗位 级联查询
- 支持部门树形选择
- 自动加载岗位选项

- 导出: `/ryManage/hrmSyqgz/exportXls`
- 导入: `ryManage/hrmSyqgz/importExcel`

### ProbationDetailModal.vue (员工详情模态框)

- 查看员工完整信息

**展示内容:**

   - 状态标签

2. **基本信息 Tab**

   - 个人信息：姓名、性别、出生日期、身份证号、手机号、邮箱
   - 其他信息：民族、籍贯、居住地、健康状况、政治面貌、婚姻状况
   - 户籍信息：户籍性质、户籍地址
   - 工作信息：入职日期、员工类型、合同类型、工作地点

3. **教育经历 Tab**

   - 学历层次
   - 毕业院校/机构
   - 专业
   - 入学时间、毕业时间
   - 学位
   - 证书编号
   - 证书附件（可预览）

4. **工作履历 Tab**

   - 工作单位
   - 所属行业
   - 任职岗位
   - 在职开始/结束时间
   - 离职原因
   - 证明人、联系电话

5. **家庭成员 Tab**

   - 姓名、关系
   - 职务、工作单位
   - 联系电话

6. **个人附件 Tab**

   - 证件类型
   - 取得日期、有效期截止日
   - 证书编号
   - 证书附件（可预览）

8. **访谈经历 Tab**

### ProbationInterviewModal.vue (添加访谈模态框)

**功能:**

- 选择访谈配置模板
- 填写访谈问题回答
- 批量保存访谈记录

**表单字段:**

- 访谈日期（必填）
- 适用职级（必填，管理/其他）
- 访谈类型（必填，自动加载问题列表）

**问题列表字段:**
| 字段名 | 显示名称 | 说明 |
|--------|---------|------|
| wtnr | 问题内容 | 从访谈配置继承 |
| ftqk | 访谈情况 | 手动填写 |
| sfywt | 是否有问题 | 单选（无/有） |
| gjr | 跟进人 | 从访谈配置继承 |

**API 接口:**

- 访谈配置列表: `/ryManage/hrmFtpz/list`
- 访谈配置详情: `/ryManage/hrmFtpz/queryDetlById`
- 批量添加访谈: `/ryManage/hrmSyqgzRzft/addBatch`

**提交逻辑:**

```javascript
{
  syzj: '入职',
  id: this.record.id || undefined,
  rzftList: this.questions.map((item) => ({
    hrmSyqgzId: this.record.id,
    ftrq: this.form.ftrq,
    ftlx: this.selectedConfig.ftlx,
    wtnr: item.wtnr,
    ftqk: item.ftqk,
    sfywt: item.sfywt,
    gjr: item.gjr,
  })),
}
```

**支持两种模式:**

- `probation`: 试用期访谈（默认）
- `daily`: 日常访谈

### ProbationRegularModal.vue (转正申请模态框)

**功能:**

- 发起员工转正申请
- 设置审批流程
- 提交转正申请

**表单字段:**

- 计划转正日期（必填，默认为试用期结束日期）
- 转正意见说明（可选）
- 审批人（必填）
- 抄送人（可选）

**员工信息展示:**

- 姓名
- 公司
- 所属部门
- 岗位名称
- 试用期开始
- 试用期结束

**API 接口:**

- 发起转正申请: `/ryManage/hrmSyqgz/applyPermanent`

**提交参数:**

```javascript
{
  gh: this.record.gh,                   // 工号
  csr: this.form.csr,                   // 抄送人
  companyId: this.record.companyId,     // 公司ID
  hrmSyqgzId: this.record.id,           // 试用期跟踪ID
  zzyj: this.form.zzyj,                 // 转正意见
  postRank: this.record.postRank,       // 职级
  dept: this.record.dept,               // 部门
  postId: this.record.postId,           // 岗位
  spr: this.form.spr,                   // 审批人
  xm: this.record.xm,                   // 姓名
  zt: this.record.zt,                   // 状态
  sjzzrq: this.form.sjzzrq,             // 计划转正日期
  jhzzrq: this.form.sjzzrq,             // 计划转正日期（副本）
  syqkssj: this.record.syqkssj,         // 试用期开始时间
  syqjssj: this.record.syqjssj          // 试用期结束时间
}
```

## 📊 数据流程

### 试用期跟踪流程

```
1. 员工入职
   ↓
2. 系统生成试用期跟踪记录
   - 状态: 试用期
   ↓
3. HR 定期添加访谈记录
   ↓
4. 试用期结束前发起转正申请
   - 状态: 未转正
   ↓
5. 审批流程
   - 通过 → 状态: 已转正
   - 拒绝 → 状态: 拒绝转正
   ↓
6. 如拒绝转正，可再次发起转正申请
```

### 添加访谈流程

```
1. 点击"添加访谈"按钮
   ↓
2. 打开 ProbationInterviewModal
   ↓
3. 选择访谈日期
   ↓
4. 选择适用职级（管理/其他）
   ↓
5. 加载访谈类型选项
   ↓
6. 选择访谈类型
   ↓
7. 自动加载问题列表
   ↓
8. 填写访谈情况
   ↓
9. 标记是否有问题
   ↓
10. 批量保存访谈记录（POST /ryManage/hrmSyqgzRzft/addBatch）
```

### 发起转正流程

```
1. 点击"转正"按钮（仅"试用期"和"拒绝转正"状态可用）
   ↓
2. 打开 ProbationRegularModal
   ↓
3. 查看员工基本信息
   ↓
4. 选择计划转正日期
   ↓
5. 填写转正意见说明
   ↓
6. 选择审批人和抄送人
   ↓
7. 提交转正申请（POST /ryManage/hrmSyqgz/applyPermanent）
   ↓

### 查看详情流程

```
1. 点击"详情"按钮
   ↓
2. 打开 ProbationDetailModal
   ↓
3. 根据工号查询员工完整信息（POST /ryManage/hrmSyqgz/queryByNo）
   ↓
4. 展示多个 Tab 信息
   - 基本信息
   - 教育经历
   - 工作履历
   - 家庭成员
   - 个人附件
   - 关系申报
   - 访谈经历
   ↓
5. 点击访谈记录"详情"查看问题回答
```

## 🔒 权限控制

- **查看权限**: 所有用户均可查看试用期员工列表和详情
- **编辑权限**: 根据用户角色控制添加访谈、发起转正等操作
- **状态权限**: "试用期"和"拒绝转正"状态才显示转正按钮

## 📝 注意事项

1. **状态管理**

   - 初始状态为"试用期"
   - 发起转正后状态变为"未转正"
   - 审批通过后状态变为"已转正"
   - 审批拒绝后状态变为"拒绝转正"
   - "拒绝转正"状态可再次发起转正

2. **访谈记录**

   - 访谈日期必填
   - 适用职级必填（管理/其他）
   - 访谈类型必填
   - 访谈情况为空时可保存
   - 问题列表从访谈配置模块继承

3. **转正申请**

   - 计划转正日期默认为试用期结束日期
   - 审批人必填
   - 抄送人可选
   - 转正意见说明可选

4. **员工详情**

   - 根据工号查询完整信息
   - 工号缺失时无法查看详情
   - 支持多个文件预览
   - 访谈经历可查看详细问答

5. **组织架构联动**

   - 公司选择后加载部门选项
   - 部门选择后加载岗位选项
   - 级联选择支持清空重置

6. **字段配置**
   - 使用 `columnCode: 'HrmSyqgz'` 作为字段配置标识
   - 配置保存后会影响列表显示的字段

## 📊 典型应用场景

```

   - 姓名: 张三
   - 部门: 技术部
   - 试用期: 2024-01-01 ~ 2024-03-31
   - 状态: 试用期
   ↓
2. HR 定期添加访谈
   - 访谈日期: 2024-02-01
   - 访谈类型: 入职访谈
   - 填写工作适应情况
   - 标记是否有问题
   ↓

   ↓

   - 状态更新: 已转正
```

   - 提交审批
   ↓

   - 状态更新: 已转正
```
