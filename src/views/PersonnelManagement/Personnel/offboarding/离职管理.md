# 离职管理模块 (Offboarding)

## 概述

离职管理模块是企业人力资源管理系统的核心模块之一，用于管理员工离职全流程，包括离职申请、审批、访谈、结算等环节。该模块采用状态机模式，确保离职流程的规范性和可追溯性。

## 核心功能

### 1. 离职状态流转

离职管理采用状态机模式，支持以下状态流转：

```
审批中 → 待离职 → 结算中 → 已离职
   ↓
已取消
```

| 状态       | 说明                     | 可执行操作         |
| ---------- | ------------------------ | ------------------ |
| **审批中** | 离职申请已提交，等待审批 | 通过、取消         |
| **待离职** | 审批已通过，等待离职     | 离职结算、确认离职 |
| **结算中** | 正在进行离职结算         | 结算处理           |
| **已离职** | 离职流程已完成           | -                  |
| **已取消** | 离职申请已取消           | -                  |

### 2. 离职申请

**功能入口**：`offboardingCreateModal.vue`

发起离职申请时需要填写以下信息：

- **离职员工**：选择待离职员工（自动填充工号、部门、岗位等基本信息）
- **预计离职日期**：只能选择今天及之后的日期
- **离职原因**：支持选择（个人发展、薪资待遇、家庭原因、工作环境、职业规划、健康原因、其他）
- **具体说明**：详细说明离职原因（选填）
- **审批流程**：选择审批人和抄送人

**API 接口**：

- 新增离职申请：`POST /ryManage/hrmLzgl/add`

### 3. 离职审批

**功能入口**：`offboardingApproveModal.vue`

审批通过后：

- 离职状态变更为「待离职」
- 可填写审批意见

**API 接口**：

- 审批接口：`PUT /ryManage/hrmLzgl/edit`

### 4. 离职访谈

**功能入口**：`offboardingInterviewModal.vue`

离职访谈支持：

- **访谈类型选择**：根据适用职级加载不同的访谈类型
- **问题列表**：自动加载对应访谈类型的问题清单
- **访谈记录**：填写每个问题的访谈情况和是否有问题
- **查看访谈**：支持查看已有的访谈记录

**API 接口**：

- 访谈配置列表：`GET /ryManage/hrmFtpz/list`
- 访谈配置详情：`GET /ryManage/hrmFtpz/queryDetlById`
- 批量添加访谈记录：`POST /ryManage/hrmLzglLzft/addBatch`

### 5. 离职结算

**功能入口**：`offboardingSettleModal.vue`

离职结算支持两种模式：

- **发起结算**（待离职 → 结算中）：添加结算子事务
- **处理结算**（结算中）：更新子事务状态

子事务包括：

- 事项名称
- 处理人
- 抄送人
- 事务状态（处理中/已完成）

**API 接口**：

- 结算接口：`PUT /ryManage/hrmLzgl/lzjsEditAll`
- 删除子事务：`DELETE /ryManage/hrmLzglLzjs/delete`

### 6. 确认离职

**功能入口**：`offboardingConfirmModal.vue`

确认离职时：

- 选择实际离职日期
- 将员工状态变更为"已离职"
- 同步更新员工档案信息
- 生成离职证明办理提醒

**API 接口**：

- 确认离职：`PUT /ryManage/hrmLzgl/confirmLeave`

### 7. 取消离职

**功能入口**：`offboardingCancelModal.vue`

取消离职时：

- 必须填写取消原因
- 离职状态变更为「已取消」

**API 接口**：

- 取消离职：`PUT /ryManage/hrmLzgl/edit`

### 8. 离职详情

**功能入口**：`offboardingDetailModal.vue`

展示离职申请的完整信息：

- **基本信息**：状态、公司、部门、岗位、工号、姓名、离职原因等
- **审批流程**：抄送人信息
- **访谈记录**：离职访谈记录列表，支持查看详情
- **离职结算子事务**：结算中/已离职状态下显示

**API 接口**：

- 离职详情：`GET /ryManage/hrmLzgl/queryDetlById`

## 主要组件说明

### index.vue - 主入口页面

**主要功能**：

- 离职记录列表展示
- 状态筛选标签页（显示各状态数量统计）
- 查询条件（工号、姓名、公司、部门）
- 字段配置（自定义显示列）

**核心方法**：
| 方法名 | 说明 |
|--------|------|
| `loadData(arg)` | 加载列表数据 |
| `getStatusTotal()` | 获取各状态统计数量 |
| `handleStatusChange(status)` | 切换状态筛选标签 |
| `handleAdd()` | 打开发起离职弹窗 |
| `handleDetail(record)` | 查看离职详情 |
| `handleApprove(record)` | 审批通过 |
| `handleInterview(record)` | 离职访谈 |
| `handleSettle(record)` | 离职结算 |
| `handleConfirm(record)` | 确认离职 |
| `handleCanceloffboarding(record)` | 取消离职 |

**API 接口**：

- 列表接口：`GET /ryManage/hrmLzgl/list`
- 状态统计：`GET /ryManage/hrmLzgl/getTotal`

## 开发注意事项

1. **日期验证**：发起离职申请时，预计离职日期不能早于今天
2. **状态校验**：操作前会校验离职状态，不符合条件时提示用户
3. **数据完整性**：所有操作前会检查记录是否包含主键 ID
4. **异步竞态处理**：访谈类型加载使用 `requestId` 防止异步请求竞态
5. **组织架构数据清洗**：加载组织架构时使用 `cleanTreeData` 确保数据结构有效
