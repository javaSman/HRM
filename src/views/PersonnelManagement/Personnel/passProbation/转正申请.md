# 转正申请模块 (Probation Regularization Application Management)

## 📋 模块概述

转正申请模块用于管理试用期员工转正申请的审批流程,提供转正申请列表查看、详情展示、审批操作等功能,是试用期跟踪模块的下游审批环节,支持完整的转正审批工作流。

## 📁 目录结构

```
passProbation/
├── index.vue                              # 主列表页面
├── passProbation.less                     # 列表页样式文件
├── 转正申请.md                             # 原有文档(空)
└── modules/
    ├── HrmSyqgzFqzzsqModal.vue            # 基础模态框(备用)
    ├── HrmSyqgzFqzzsqModal.Style#Drawer.vue # 抽屉样式模态框(备用)
    ├── HrmSyqgzFqzzsqForm.vue             # 基础表单组件(备用)
    ├── RegularDetailModal.vue             # 转正申请详情模态框
    └── RegularApproveModal.vue            # 转正审批模态框
```

## 🎯 功能特性

### 1. 转正申请列表

- 支持分页展示转正申请记录
- 多维度筛选查询（公司、部门、岗位、工号、姓名、试用期时间）
- 状态标签可视化展示
- 字段自定义配置

### 2. 状态管理

支持 4 种状态:

- **全部**: 显示所有转正申请记录
- **已转正**: 绿色标签 (#55c42a) - 审批通过
- **未转正**: 橙色标签 (#e6a23c) - 待审批
- **拒绝转正**: 红色标签 (#f56c6c) - 审批拒绝

### 3. 核心操作功能

#### 查看详情

- 查看员工基本信息
- 查看转正意见
- 查看审批流程（时间轴展示）

#### 转正审批

- 查看申请人和员工信息
- 填写审批意见（必填）
- 通过/不通过操作
- 自动更新状态

### 4. 字段配置

- 支持自定义列表字段显示
- 可配置字段显示/隐藏
- 字段配置标识: `HrmSyqgzFqzzsq`

### 5. 组织架构联动

- 公司 → 部门 → 岗位 级联查询
- 支持部门树形选择
- 自动加载岗位选项

## 📊 数据流程

### 转正审批流程

```
1. 试用期跟踪模块发起转正申请
   - 状态: 未转正
   - 记录生成: hrmSyqgzFqzzsq 表
   ↓
2. 审批人收到待办通知
   ↓
3. 打开转正申请模块
   - 查看转正申请列表
   - 筛选"未转正"状态
   ↓
4. 点击"审批"按钮
   - 打开审批模态框
   - 查看申请人和员工信息
   ↓
5. 填写审批意见（必填）
   ↓
6a. 通过审批
   - 点击"通过"按钮
   - 调用审批接口 (POST /ryManage/hrmSyqgzFqzzsq/approve)
   - 状态更新: 已转正
   ↓
6b. 拒绝审批
   - 点击"不通过"按钮
   - 调用编辑接口 (POST /ryManage/hrmSyqgzFqzzsq/edit)
   - 状态更新: 拒绝转正
```

### 查看详情流程

```
1. 点击"详情"按钮
   ↓
2. 打开详情模态框
   ↓
3. 查询申请详情 (GET /ryManage/hrmSyqgzFqzzsq/queryById)
   ↓
4. 展示基本信息
   - 姓名、工号、公司
   - 部门、岗位、职级
   - 试用期时间、计划转正日期
   ↓
5. 切换 Tab 查看详细信息
   - 转正意见 Tab: 查看转正意见内容
   - 审批流程 Tab: 查看审批流程时间轴
```

## 🔒 权限控制

- **查看权限**: 所有用户均可查看转正申请列表和详情
- **审批权限**: 根据用户角色控制审批操作
- **状态权限**: 仅"未转正"状态显示审批按钮

## 📝 注意事项

1. **状态管理**

   - 初始状态为"未转正"（由试用期跟踪模块发起）
   - 审批通过后状态变为"已转正"
   - 审批拒绝后状态变为"拒绝转正"
   - 状态不可逆转

2. **审批意见**

   - 审批意见为必填项
   - 支持多行文本输入
   - 自动调节高度（4-6 行）

3. **数据来源**

   - 转正申请记录由试用期跟踪模块生成
   - 本模块仅负责审批处理
   - 不支持手动新增转正申请

4. **组织架构联动**

   - 公司选择后加载部门选项
   - 部门选择后加载岗位选项
   - 级联选择支持清空重置

5. **字段配置**

   - 使用 `columnCode: 'HrmSyqgzFqzzsq'` 作为字段配置标识
   - 配置保存后会影响列表显示的字段

6. **审批流程**
   - 审批流程数据从后端获取
   - 时间轴展示审批进度
   - 支持多种状态展示（done/current/rejected）

## 🔍 与其他模块的关系

### 关联模块

- **试用期跟踪**: 上游模块，发起转正申请
- **员工管理**: 提供员工基本信息

### 数据流向

```
试用期跟踪模块
   ↓
发起转正申请
   ↓
转正申请模块（审批流程）
   ↓
审批通过 → 已转正
审批拒绝 → 拒绝转正
   ↓
更新员工状态
```

### 业务关联

```
试用期跟踪:
  - 员工试用期管理
  - 定期访谈记录
  - 发起转正申请
  - 状态: 试用期 → 未转正

转正申请:
  - 转正申请列表
  - 审批流程处理
  - 状态更新
  - 状态: 未转正 → 已转正/拒绝转正
```

## 📊 典型应用场景

### 场景 1: 审批转正申请

```
1. 试用期员工张三发起转正申请
   - 部门: 技术部
   - 试用期: 2024-01-01 ~ 2024-03-31
   - 计划转正日期: 2024-04-01
   - 状态: 未转正
   ↓
2. 部门经理收到审批通知
   ↓
3. 打开转正申请模块
   - 筛选"未转正"状态
   - 查看张三的转正申请
   ↓
4. 点击"详情"查看完整信息
   - 查看转正意见
   - 查看访谈记录
   ↓
5. 点击"审批"进行审批
   - 填写审批意见: "工作表现优秀，同意转正"
   - 点击"通过"按钮
   ↓
6. 状态更新为"已转正"
```

### 场景 2: 拒绝转正申请

```
1. 试用期员工李四发起转正申请
   - 部门: 销售部
   - 试用期: 2024-01-01 ~ 2024-03-31
   - 状态: 未转正
   ↓
2. 部门经理查看转正申请
   ↓
3. 进行审批
   - 填写审批意见: "业绩未达标，暂不转正"
   - 点击"不通过"按钮
   ↓
4. 状态更新为"拒绝转正"
   ↓
5. 可在试用期跟踪模块再次发起转正
```

### 场景 3: 查看审批流程

```
1. 点击转正申请记录的"详情"按钮
   ↓
2. 查看基本信息
   - 员工信息、试用期时间等
   ↓
3. 切换到"审批流程" Tab
   ↓
4. 查看审批时间轴
   - 节点1: 部门经理审批 - 已完成（绿色圆点）
   - 节点2: HR 审批 - 进行中（蓝色圆点）
   - 节点3: 总经理审批 - 待处理（灰色圆点）
```
