# 打卡管理模块

> 员工打卡记录管理

## 概述

打卡管理模块负责管理员工的打卡记录，包括打卡数据采集、记录查询、规则配置等。

## 子模块

| 目录 | 功能 |
|------|------|
| `clockIn/` | 打卡记录 |

## 核心功能

- 打卡记录查询
- 打卡数据统计
- 补卡申请处理
- 打卡规则配置

## 打卡方式

- 人脸识别打卡
- 指纹打卡
- 手机定位打卡
- 二维码打卡
